# 派生值登记表

> **为什么要这个文件**：本项目的纪律是"每个数字都能指向一个产物文件"。
> 但论文里有一类数字是**算出来的**（均值、差值、比值），它们在源文件里**不以那个形式存在**——
> 复核的人必须知道"怎么算的"才复得出来。
>
> **用途**：任何写进论文而**不能字面命中源文件**的数字，都在这里登记它的算式与原始行。
>
> **怎么发现的**：用一次全文数字溯源扫描（抽出稿件里每一个数值 token，
> 反向在全部源材料里找，允许四舍五入匹配）。扫出的"无出处"项就是这里要登记的。
> 最近一次扫描：journal 240 个 token、technical-report 191 个，**四舍五入后仍无出处 2 个**（都在 journal）。

## 二、登记规则（以后照此办）

1. **只登记"不能字面命中"的**。均值/差值如果恰好等于某个已存值（例如三行同值），不必登记。
2. **必须写清三件**：① 哪几个文件；② 取哪一行哪一列；③ 怎么合成（平均/相减/相除）。
3. **每次往论文里加派生值后，重跑一次全文扫描**，把新出现的无出处项补进来。
4. **不许只写"由产物算出"** —— 那等于没写，复核的人复不出来。

---

## 三、扫描方法（可复现）

抽出稿件里所有形如 `\d+\.\d+` 的 token，排除纯格式数字（`0.5cm`、`11pt` 之类）
与一组通用常数（0.5 / 1.5 / 0.95 等）；
然后在**全部源材料**（论文 + 台账 + 四份阶段报告 + `deploy_notes.md` + `docs/*.md` +
`results_master.csv` + `outputs*/**/*.csv`）里查：
① 字面命中；② **四舍五入到 1/2/3 位小数后命中**（论文写 3 位、源文件常存 6 位，这一条是必须的）。

只用①会误报（第一版扫描报了 4 个，其中 2 个是四舍五入造成的假阳性）。
