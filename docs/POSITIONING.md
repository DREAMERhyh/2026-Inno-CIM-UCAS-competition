# 本项目与已有工作的关系（M0b 交付物）

> **为什么要写这个**：2026-09 的文献检索查出——**本项目最核心的方法在文献里有名字**。
> 「冻结主干、只训读出」= **linear probing**，而「LP 在分布外能赢过全量微调」
> 是一条 2022 年就有理论支撑的已知结论。
> 不把这件事说清楚，后面所有实验都会建在一个没说清的位置上。
>
> **核实状态**：本文只引用已抓到原文摘要逐字核对过的文献（`docs/LITERATURE_NOTES.md` 标 ✅ 者）。
> 标 ⚠ 的一律不进本文的论断。

## 一、一句话定位

> **本项目把一个已有理论支撑的方法学事实（"冻结主干 + 只训读出"能在分布外胜过全量微调），
> 迁移到一个新场景——模拟域非理想性下的存算一体推理——并给出该场景特有的三件东西：
> 可恢复量的量（探针 headroom）、损伤的机制（有效秩塌陷）、修复的边界（门控两前提）。
> 此外本研究独立发现了一个与读出正交的架构杠杆（池化降维）。**

**不是**"我们发明了冻结主干只训读出"——那是 linear probing，早就有。
**是**"我们证明在这个场景下它不是'更好的选择'而是'唯一的选择'，并说清了它的量、机制和边界"。

## 二、与三条先行工作的关系

### 2.1 最接近的方法学工作：LP-FT（Kumar et al., ICLR 2022）

**它做了什么**（arXiv:2202.10054，摘要**已逐字核实**）：

> "full fine-tuning … **can achieve worse accuracy than linear probing out-of-distribution (OOD)
> when the pretrained features are good and the distribution shift is large**."
> "On 10 distribution shift datasets …, fine-tuning obtains on average **2% higher accuracy ID
> but 7% lower accuracy OOD** than linear probing."
> 机制名：**feature distortion** —— "while fine-tuning learns the head, the lower layers
> of the neural network change simultaneously and **distort the pretrained features**".
> 提出 **LP-FT**（先线性探针、再全量微调）："**1% better ID, 10% better OOD** than full fine-tuning".

**本项目做了什么**：在 CIFAR-100/CIFAR-10、四个主干上，实测"训练端四条路径全部无效、
冻结主干只训读出最好"，并**测出了原因**（探针 headroom +20.12 pp、有效秩塌陷 20.6~58.7%）。

| | 它 | 本项目 |
|---|---|---|
| 场景 | 分布偏移（OOD，10 个数据集） | **模拟域非理想性**（确定性的、逐层累积的输入侧失真） |
| 论据 | 准确率（ID/OOD 各一组数） | 准确率 **+ 表征几何**（秩、Fisher、探针 headroom） |
| 机制 | 归因到 "feature distortion" | **给出可测量的形态**：维度丢失而非类间距缩小 |
| 代价 | LP 有 ID 代价，用 LP-FT 补 | **读出适配的 clean 代价，用在线 α 估计 + 门控收回来** |
| 架构维度 | 无 | **池化密度是一个与读出正交的独立杠杆** |

**✅ 这是差异化，不是重复。** 但论文**必须显式引用它**，并说明上表逐行。
**不写 = 审稿人一句"这不就是 LP 吗"就能打掉。**

**被覆盖点（诚实说）**：
- "冻结主干比全量微调在分布外更好" —— **不是本项目的贡献**，是已知结论。
- 本项目**没有**测 LP-FT（先探针再微调）这条两步策略。已列入 M8c。

### 2.2 最接近的领域工作：CIM 的免片上训练校准

**它做了什么**（*Science Advances* 10(38):eadp3710, 2024，**标题/作者/DOI 已核实**；
T. Xiao, V. B. Naik, J. H. Lim, Y. Hou, Z. Wang, Q. Shao）：

MTJ 存内计算 + **离线标定**，达软件基线精度、**无需昂贵的片上训练**；
核心手段是**自适应量化（用电导漂移感测测出真实电导相对目标值的偏差）**。

同类（⚠ 尚未逐条核实，仅列名不作论断）：
Nature Communications 的 PCM 工作用**数字域缩放因子**补偿电导漂移（"without any expensive re-programming"）；
IGZO DRAM 阵列用**免刷新的时变 ADC 校准**。

**它们的共同形态**：**标量 / 查找表级的数字域校正**——调缩放因子、调量化档位、调 ADC 参数。

**本项目做了什么**：同样"冻结阵列、只在数字域动手"，但**动的对象不同**——
不是调标量，而是**重训整个线性读出层**，并且：

| | 先行工作 | 本项目 |
|---|---|---|
| 补偿对象 | 电导漂移 / 量化档位（**标量级**） | **读出的线性可解码性**（**一层参数**） |
| 是否重训 | 否（查表/调参） | **是**（只训那一层，占全模型参数 5.04%/0.55%） |
| 是否给上界 | 否 | **给**：探针 headroom 是可恢复量的量度 |
| 是否给机制 | 部分（漂移的物理模型） | **给**：秩塌陷 |
| 是否给边界 | 否 | **给**：门控两前提 + 读出层必须在数字域的结构前提 |
| 失真模型 | 真实器件（漂移、量化） | **参数化（三次多项式）**，无硬件实测 ← **本项目的短板** |

**✅ 差异化成立**，但**姿态要放低**：本项目是**一个更"重"的补偿形式**，
代价是它要求读出层可重写，而先行工作只要数字域能调标量。
**这条必须写进 limitation 与工程章节。**

**被覆盖点**：
- "数字域补偿冻结的模拟权重"这个**思路本身** —— **不是本项目的贡献**。
- "读出层要在数字域"这个**结构性要求** —— 先行工作已隐含（它们本来就在数字域做）。

### 2.3 测量层的警示：线性探针会被误读

**它做了什么**（arXiv:2608.20516，**逐字核实**）：

> "linear-probe accuracy 0.871 and effective rank 18-47, **yet retrieval recovers 0.00 of 14.4 bits**"
> "**Rank, probes, and metrics can all saturate on an unsupportive evaluation.**"

以及 fragility（arXiv:2606.11375，**逐字核实**）：探针精度饱和后仍可用"激活噪声下精度崩塌的临界点"分辨，
且**必须用 RMS 归一化**（否则大激活的深层会虚假显得更鲁棒）。

**本项目做了什么**：headroom +20.12 是**单点探针读数**——正是被警示的那一类。
**已列入 M0c**：加四组对照（随机标签 / fragility / decoder-vs-activation / 私有划分）。

**✅ 这不是差异化，是"本项目承认自己踩在被警示的方法上，并去加固它"。**
这条要**主动写进论文**——主动承认比被审稿人指出好。

## 三、本项目的三条差异化（写进论文 Contribution 的那三条）

1. **定位与机制**：把 LP 的优势规律搬到"权重物理上不可重训"的 CIM 场景，
   并给出**可测量的损伤形态**——正侧失真下有效秩掉 20.6~58.7%、而 **Fisher 反而升高**，
   即"丢的是维度，不是类间距"。
2. **上界与边界**：给出读出适配的**上界**（探针 headroom +20.12 pp，且高斯对照只有 +7.00，
   说明这个量本身有区分力）与**边界**（门控的两个前提；读出层必须在数字域）。
3. **第二个杠杆**：池化密度是**零训练成本、与读出正交**的独立架构杠杆（+14.38 pp），
   其保护**主要来自降维**（三条排除线：非吸收失真、非不变区集中、非 max 选择性）。
   这块在先行工作里**没有对应物**。

## 六、一句话给审稿人

> 本研究的核心方法（冻结主干、只训读出）**不是一个新方法**——它是 linear probing，
> 且"它在分布外胜过全量微调"有 2022 年的理论与十数据集实证支撑。
> **本研究的贡献是把这条规律搬到一个新场景（模拟域非理想性），
> 并给出该场景特有的量（可恢复上界）、机制（秩塌陷）与边界（门控两前提）；
> 以及一个先行工作里没有的、与读出正交的架构杠杆（池化降维）。**
> 我们同时主动加固了本项目最依赖的测量手段（线性探针），因为文献已警示它可能虚假饱和。
