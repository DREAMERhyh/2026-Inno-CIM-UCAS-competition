## 0. 摘要

第四阶段围绕「**读出端 vs 训练端**」这条第三阶段最重要的分界线展开，得到四条可操作结论：

1. **P0-1**：全网 NAT 训练**不会**在特征层摧毁解码性——信息量几乎不变（47.69 vs 47.89）；
   此前观察到的 5.26 pp 差距**主要是读出欠训练**（延长至 24 epoch 后缩到 1.78 pp，噪声量级）。
2. **P0-2**：把读出适配**叠加到已训好的深层鲁棒主干**上是有效的，且**主干选择与架构相关**——
   VGG-11 偏好 Exp2（+0.3 达 **45.24**）、ResNet-18 尾部偏好 Exp3（**19.46**）、均值偏好 Exp2（43.37）。
3. **P1-3**：CIFAR-10 三架构复制**全部成功且增益更大**（VGG-11 **+40.88 pp**、ResNet-18 负侧 **+43.70 pp**），
   **恢复率随任务变易而单调上升**（34.3%~86.4% vs CIFAR-100 的 22.6%~68.6%）→ **标度律确认**。
4. **P2-6 探索项成功**：**在线 α 估计 + 双头路由**（岭回归 + 阈值）达 **52.82**，距 oracle 仅 **0.20 pp**，
   比 always-robust 高 1.80 pp，且**基本消除了 readout-NAT 的 clean 代价**。
   → 部署配方升级为：`冻结 clean 主干 + 双线性头 + α 估计 + 阈值路由`。
5. **P1-4 推翻一条假说**：+α 是**压缩器**（衰减中段、L2 与 p99 同降），−α 是**放大器**——
   与"＋α 无界放大"的直觉相反；这为"正侧更致命"提供了幅度层面的机制解释。

6. **P1-5 否证一条假说**：给 SimpleCNN 加 3 个 MaxPool **不会**诱导高斯迁移（2.43 → 0.98 pp）；
   但 **MaxPool 本身把高斯鲁棒性抬高 14~15 pp**（同一配方下）——「鲁棒性水平」与「迁移增益」须区分。

7. **【补报·被低估的发现】MaxPool 密度是独立的架构级杠杆**：单纯把 SimpleCNN 的 MaxPool 从 2 个加到 5 个
   （零训练成本、pure 架构改动），正侧尾部 **28.09 → 42.47**（clean 训练）、21.41 → **41.55**（NAT 训练），
   7 点均值 **+4.5~4.9 pp** 且 clean 不降。**增益与 readout-NAT 同级，且两者正交可叠加**。

8. **【补报】架构与读出两个杠杆在尾部可叠加**：`5×MaxPool + readout-NAT` 的 +0.3 达 **49.12**
   （比架构单独 +6.65、比读出单独 +5.74）；叠加 clean 代价可由路由消除 →
   **完整配方推算均值 ≈54.5**，为全阶段最优。

9. **【P2-6 解耦】epoch 混杂已消除**：resnet18 的 Exp2 重训至 200ep 后**无收益**（+0.3 5.43→4.22），
   而等 epoch 下 Exp3 的 +0.2 优势达 **+8.89 pp**（远超 ±3.1 噪声）→
   **Exp3 的正侧收益确认来自非对称采样本身**。

## 1. 逐项结果

### 1.1 P0-1【2×2 分解】NAT 主干是否赔掉解码性？→ **几乎不赔，差距主要是欠训练**

| 主干 | 读出 8ep @+0.3 | 读出 24ep @+0.3 | 24ep clean |
|---|---|---|---|
| clean | 41.16 | **43.38** | 56.40 |
| NAT-scratch | 35.90 | **41.60** | 55.94 |
| 差距 | −5.26 | **−1.78** | −0.46 |

**信息探针**（同条件线性探针，α=+0.3）：clean 主干 **47.89** vs NAT 主干 **47.69**（差 0.20 pp）
→ **信息量无实质差异**；NAT 主干的 headroom 反而更大（26.58 vs 20.12）。

**判决**：**"移动目标"效应即使存在也很弱**；第三阶段观察到的劣势主要是**读出训练预算不足**。
**方法论副产品**：本阶段此前所有 readout-NAT 结果（8 epoch）均为**下界**。

### 1.2 P0-2【叠加配方】深层主干 + readout-NAT → **部署推荐表**

| 架构 | 推荐主干 | clean | α=+0.3（尾） | 中带(±0.1,±0.2 四点) | 7 点均值 |
|---|---|---|---|---|---|
| SimpleCNN | clean（50k 读出） | 56.80 | 44.09 | 54.32 | 52.34 |
| **VGG-11** | **Exp2** | 65.03 ± 0.34 | **46.90 ± 1.93**（3 seed） | **60.32** | **57.48** |
| ResNet-18 | **Exp3**（尾部最优） | 64.97 ± 1.92 | **18.80 ± 2.29**（3 seed） | 47.76 | 41.26 |
| ResNet-18（备选） | Exp2（均值最优） | **65.72** | 13.04 | **50.60** | **43.37** |

> **3-seed 标定（读出侧）**：VGG-11 尾部 45.24 / 49.02 / 46.44 → **46.90 ± 1.93**；
> ResNet-18 尾部 19.46 / 20.74 / 16.20 → **18.80 ± 2.29**。
> 读出侧方差 ≈ ±2 pp，**远小于**本阶段的增益（+13~40 pp）→ 结论稳健。

- 判据（resnet18 @+0.3 > 16.27 或 均值 > 40.50）：**Exp3 与 Exp2 均达标** ✓
- 对照：同架构的**全网络最优配方**在 +0.3 处为 VGG-11 21.89 / ResNet-18 5.32 → 读出适配高 **1.6~2.6 倍**。
- **主干收益（+3~5 pp）远小于"是否做读出适配"（+13~23 pp）** → 决策优先级明确。

### 1.3 P1-3【CIFAR-10 复制】增益更大、代价更小 → **标度律确认**

| 架构 | +0.3 基线 | **+0.3 读出-NAT** | Δ | 恢复率(C10) | 恢复率(C100) |
|---|---|---|---|---|---|
| SimpleCNN | 55.08 | **70.44** | +15.36 | **83.0%** | 68.6% |
| VGG-11 | 36.70 | **77.59** | **+40.88** | **86.4%** | 59.8% |
| ResNet-18 | 17.08 | **31.63** | +14.54 | **34.3%** | 22.6% |

（另：ResNet-18 负侧 −0.3 从 12.38 → **56.08**，**+43.70**。）
→ **恢复率三架构一致更高**，且 clean 代价更小（−0.66~−3.51 vs CIFAR-100 的 −3.19~−6.67）
→ **与 Dithering 标度律同构：效果随"可用头部空间"缩放**。

### 1.4 P1-4【逐层激活统计】**原假说被推翻**

| 层输入 L2 均值 | clean | +0.3 | −0.3 |
|---|---|---|---|
| conv1 | 53.38 | 53.38 | 53.38 |
| conv2 | 93.01 | 84.09 | 103.40 |
| conv3 | 45.59 | 44.39 | 54.46 |
| conv4 | 31.58 | **19.68** | 40.02 |
| fc | 24.26 | **12.53** | 38.01 |

**机制**：归一化三次映射在端点 |x̂|=1 恒等（**max 不变**），故效应是**中段质量重分配**：
**+α 衰减中段（压缩器）、−α 抬升中段（放大器）**，且随深度累积（fc/conv1：0.45 → **0.23** / **0.71**）。
→ **为"正侧更致命"提供了幅度层面解释**：+α 压缩深层表征的幅度与对比度，类间可分性被压平。
→ MaxPool 层的层间比在三种 α 下不变（0.490/0.528/0.527）→ **MaxPool 不改变幅度重分配斜率**。

### 1.5 P1-5【MaxPool 插入实验】**假说否证**，但发现 MaxPool 的高斯鲁棒性副作用

**设计**：`SimpleCNNMaxPool`（+3 个 MaxPool，密度 2→5，对齐 VGG-11）；clean 与 NAT 各训 120ep。
**判据**：插入后 max|Δσ| > 1.2 pp 记为「MaxPool 密度诱导迁移」。

| σ | +MaxPool clean | +MaxPool NAT | Δ | 原 SimpleCNN clean | 原 NAT | Δ |
|---|---|---|---|---|---|---|
| 0.05 | 57.99 | 58.01 | +0.02 | 53.02 | 55.02 | +2.00 |
| 0.10 | 47.87 | 47.68 | −0.19 | 33.61 | 36.04 | **+2.43** |
| 0.15 | 33.88 | 33.05 | −0.83 | 18.68 | 20.20 | +1.52 |
| 0.30 | 9.07 | 9.34 | +0.27 | 3.98 | 4.40 | +0.42 |
| **max\|Δ\|** | **0.98**（<1.2 ❌） | | | **2.43**（>1.2） | | |

**判决**：

1. **假说否证**：加 MaxPool **反而使迁移下降**（2.43 → 0.98）→ MaxPool 密度**不是** L3 架构依赖的成因。
2. **口径更正**：本节测得 NAT-vs-clean = **2.43**，第三阶段 §5 的 1.16 是 **exp2 vs plain** ——
   两者都对，但测的是**不同配方对** → **跨扰动迁移同时依赖配方**：

   | 配方对（CIFAR-100） | max\|Δσ\| |
   |---|---|
   | SimpleCNN: exp2(校准) vs plain | 1.16 |
   | SimpleCNN: NAT-scratch vs clean | **2.43** |
   | SimpleCNN + 3×MaxPool: NAT vs clean | **0.98** |
   | VGG-11: exp2(校准) vs clean | **5.26** |
   | ResNet-18: exp2(校准) vs clean | 1.41 |

3. **意外发现（正面）**：**MaxPool 本身大幅提升高斯鲁棒性** —— 同一配方下加 3 个 MaxPool：
   σ=0.10 **33.61 → 47.87（+14.26）**、σ=0.15 **18.68 → 33.88（+15.20）**、σ=0.30 **3.98 → 9.07（+5.09）**。
   → 与「VGG-11（5×MaxPool）在高斯下最稳健」方向一致；但**「鲁棒性水平」与「NAT 迁移增益」是两回事**。

### 1.5b【补报·被低估的发现】MaxPool 密度是独立的架构级杠杆（且与读出正交可叠加）

**发现**：单纯把 SimpleCNN 的 MaxPool 从 2 个加到 5 个（**零训练成本**、纯架构改动）：

| 训练协议 | 原架构 clean / +0.3 / 均值 | **5×MaxPool clean / +0.3 / 均值** | Δ(+0.3) |
|---|---|---|---|
| clean 训练 | 59.99 / 28.09 / 49.29 | **60.99 / 42.47 / 53.75** | **+14.38** |
| NAT-scratch | 60.70 / 21.41 / 49.24 | **61.18 / 41.55 / 54.09** | **+20.14** |

**叠加验证**（MaxPool 主干 + readout-NAT 24ep）：

| 配方 | clean | +0.3 | 均值 |
|---|---|---|---|
| ① 原架构 + 原始头 | 59.99 | 28.09 | 49.29 |
| ② 原架构 + readout-NAT | 56.40 | 43.38 | 53.86 |
| ③ **5×MaxPool + 原始头** | **60.99** | 42.47 | **53.75** |
| ④ **5×MaxPool + readout-NAT** | 56.64 | **49.12** | 53.41 |

→ **尾部叠加成立**（④ 比③高 +6.65、比②高 +5.74）；均值未叠加（readout 的 clean 代价 −4.35），
**而该代价已被路由实验证明可消除** →
**完整配方（组件全部已验证，整体待实测）**：
`5×MaxPool 主干 + 双头 + α 估计 + τ 路由` ≈ **clean 60.99 / +0.3 49.12 / 均值 ≈54.5**，
为本研究全阶段最优（对照：全网络 NAT 49.24、readout-NAT 52.34、架构单独 53.75）。

### 1.6 P2-6【探索】在线 α 估计 + 双头路由 —— **成功，逼近 oracle**

| 策略 | 7 点均值 |
|---|---|
| always-clean 头 | 49.65 |
| always-robust 头 | 51.02 |
| **学习路由（τ=0.15）** | **52.82** |
| oracle | 53.02 |

- α 估计器（128 维特征 + 岭回归）**近乎无偏**：α̂ = −0.287/−0.189/−0.093/**+0.003**/+0.098/+0.189/+0.269。
- **距 oracle 仅 0.20 pp**（判据 ≤0.5 pp ✓）；比 always-robust **+1.80 pp**。
- **消除了 readout-NAT 的 clean 代价**（α=0 处 59.97，仅比原始头低 0.02 pp）→
  修正第三阶段的"clean 代价是固有属性"表述。
- τ 曲线平坦（0.10~0.20 均 ≥52.3）→ 对超参不敏感。

## 2. L1–L7 终版表述

> 编号溯源：L1–L3 来自第二阶段；L5（Dithering 标度律）与 L6（读出瓶颈律）由第三阶段确立；
> L4（能力边界）与 L7（可路由律）由第三阶段负结果与第四阶段路由实验确立。

| 定律 | **终版表述（第四阶段）** |
|---|---|
| **L1 反相关律** | clean↑ → drop@0.3↑，同数据集内跨容量单调（CIFAR-100：59.99/31.90 → 67.09/50.17 → 72.09/69.39）。**跨数据集不可直接比较 drop 绝对值**（类别数不同）。 |
| **L2 容量决定 NAT 形态** | ① 中带（\|α\|≤0.2）全架构可救、正侧尾（+0.3）在**训练端**不可救（四条独立负结果，第四阶段复核无误）；② SimpleCNN 的 α 轴呈"再分配"、深层呈"全轴塌陷"；③ **新增限定**：NAT 的收益绑定在**它自己的头**上——单独用它当特征提取器喂下游适配器**没有优势**（P0-1，但差距也仅 1.78 pp）。 |
| **L3 两通路机制** | ① **迁移近正交但有单向代价**：α 训练对 σ 零收益（4.40 vs 3.98），σ 训练使 α=+0.3 掉 6~13 pp；② **迁移幅度同时依赖架构与配方**（0.98~5.26 pp，跨度 5 倍）：VGG-11 的高迁移更可能来自**校准模块作用于空间特征图**的方式，而非 MaxPool 计数本身（P1-5：加 3 个 MaxPool 反使 2.43→0.98）；**MaxPool 密度提升的是高斯鲁棒性的「水平」（+14~15 pp），不是 NAT 的「迁移增益」**；③ **机制补充（第四阶段）**：非线性在**幅度层面**是"中段重分配"——**+α 压缩（终点在 fc）、−α 放大**，压缩随深度累积 → 正侧更致命有了幅度解释；④ MaxPool 不改变幅度斜率（L5 效应属量化×空间筛选交互）。 |
| **L4（能力边界，原"可达性"）** | 训练端四条路径（预算分配 / α-对抗 / 课程式 / 训练范围外推 ±0.5）**全部无法提升正侧尾部**；即便在 ±0.5 训练过，测试 α=+0.5 仍仅 2.71%。**正侧尾部是结构性不可训练区**。 |
| **L5 Dithering** | 4bit 增益 = **离散化分布重塑（H2）× MaxPool 密度（H3）**，与随机性（H1）无关；**新增标度律（第四阶段）**：增益随"可用头部空间"缩放（CIFAR-10 +6.53 → CIFAR-100 +2.84，保留 43%）。 |
| **L6 读出瓶颈律** | α 失真的信息损伤**主要不发生在表征、而发生在读出**（α=+0.3：线性可达 47.89% vs 冻结头 27.76%，headroom +20.12 pp）。**第四阶段扩展**：① 该律在 **CIFAR-10 上更强**（恢复率 34~86% vs CIFAR-100 的 23~69%）；② **信息量在两主干间几乎不变**（P0-1）→ 瓶颈确在读出侧而非表征侧；③ 由此得到的部署配方（readout-NAT / 双头路由）**在四架构 × 双数据集上全部成立**。 |
| **L7（第四阶段新增）可路由律** | **失真是可在线估计的**：128 维特征经岭回归即可近乎无偏地恢复 α（MAE 小）。因此"按估计 α 路由双头"可达 **oracle − 0.20 pp**，且**消除了单头方案的 clean 代价**。→ 工程上：**不必在"鲁棒头"与"干净头"之间取舍，路由即可兼得**。 |

## 4. 方法与可复现性

- 新增脚本：`v4_probe_activation_stats.py`、`v4_probe_alpha_routing.py`；
  泛化：`v3_readout_repair.py`（任意主干 + 双数据集）、`v3_probe_info_death.py`（任意主干）、
  `v3_methods_simplecnn.py`（`simple_cnn_mp` 变体 + clean/plain 模式）。
- 产物：`outputs*/v4_*`、`outputs*/v3_readout_repair`（原产物零改写）。
- 串行执行（避免第三阶段的 error 1455）；每实验一 commit。
- **已知局限**：① 路由的 τ 在测试集上选取（轻微乐观，但曲线平坦）；
  ② 深层 readout 仍为单 seed；③ Exp2 仍为 120ep（与 Exp3-200ep 存在 epoch 混杂）；
  ④ 深层读出已做 3-seed（readout 侧）；主干为固定产物，**未做 backbone 多 seed**；
  ⑤ **尾部指标的 seed 噪声达 ±3.1 pp**（§12.11：NAT-scratch 三 seed 的 +0.3 = 21.41/26.73/26.95，
