# 给导师的微信话术（2026-10-19）

> 用途：先发给现任学业导师（方向不同，但平时较熟），请他帮忙引荐一位方向对口的老师。
> 原则：不夸大、不说“原创方法”、先把项目是什么和走到哪一步说清楚；附件用一页摘要（`paper/advisor-summary/main.pdf`）。

## 第一版（推荐，约 300 字）

X 老师，您好！打扰您一下。我之前做的存算一体芯片非线性失真的项目，竞赛已经结束了，主办方那边也不要求出版。赛后我把实验和分析又扩了一轮，现在整理成了一篇期刊稿和一份技术报告，想试试在保研之前投出去。

项目本身是做模拟存算一体里一种确定性的非线性失真。重点不是提出新的训练方法（“冻结阵列、只更新少量参数”在 2020 年 Nature 的忆阻器混合训练里已经有先例），而是回答三个问题：失真到底损坏了哪一层、读出侧还能恢复多少、修复的边界在哪。全部结果目前是参数化模型的仿真，没有硬件实测，这一点我在稿子里写明了。

我知道您的主要方向不是这个，所以想请您帮个忙：您那边有没有做存算一体、模拟计算或神经网络鲁棒性的老师，方便帮我引荐一下吗？主要是想请方向对口的老师帮我把把关，看看现在这个定位值不值得投、投哪里合适。我附了一页摘要，您要是方便可以先扫一眼。

不着急，您方便的时候回我就行，谢谢老师！

## 第二版（更短，适合先试探）

X 老师好！之前那个存算一体的项目竞赛结束了，赛后我把工作扩写了一篇期刊稿，想赶在保研前投出去。想请您帮我引荐一位做存算一体 / 模拟计算 / 网络鲁棒性的老师，帮我把把关、看看投哪里合适。附件是一页摘要。您方便的时候回我就行，谢谢老师！

## 发之前检查

- 附件只发一页摘要，不要一上来发 30 页 PDF。
- 不说“四份稿”“填补空白”“首次提出”“零成本”这类容易被追问的话。
- 主动说“方法是已有的，卖点在诊断/上界/机制/边界”，比被老师问出来好。
- 如果老师问“你想不想做这个方向”，如实说“目前还在了解，不想为了投稿勉强承诺”；不要为了拿到推荐或经费而假装要读他的方向。

## 关于版面费 / 报销（不要在第一封信里问）

- 期刊的版面费/开放获取费通常由**通讯作者或其课题组经费**承担；学生私下找一位还没确定关系的老师报销，容易被理解为“已经答应进组”。
- 在没决定是否做这个方向之前，**不要主动提钱**。先问“值不值得投、投哪里”，等方向老师明确愿意指导、并且通讯作者安排确定后，再由通讯作者那边走经费。
- 如果老师主动问费用，可以如实说：“我这边可以承担一部分，主要想先请您看看工作本身值不值得投。”
- 竞赛主办方已经明确不要求出版，所以没有“必须给他们投稿”的义务；不要为了报销把版权或署名让出去。
