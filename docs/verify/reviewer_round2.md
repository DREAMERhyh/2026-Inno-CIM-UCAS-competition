### F03 `F03_readout_nat.png` — 一致，但有辨认缺陷

**图注说**：实线 = readout-NAT，虚线 = 各模型自带的分类头；每个主干 3 种子逐点均值；α=+0.3 处标注 = 均值±总体标准差。

**实际显示**：三条实线 + **三条灰色虚线**。数值我按 `outputs_cifar100/v3_readout_repair/*ep24*.csv` 重算 3-seed：
47.79±3.18（VGG-11）、43.31±0.16（SimpleCNN）、26.82±3.40（ResNet-18）——**与图上的 47.8±3.18 / 43.3±0.16 / 26.8±3.40 逐位一致 ✓**。

**问题**：
1. **（中）三条虚线共用一个图例项**「原始分类头」。读者看到三条灰虚线，**无法判断哪条属于哪个主干**——而这张图的论点恰恰是"每个主干各自的：原头 → 读出"的配对比较。在 α=−0.3 处，**ResNet-18 的原头（3.25）低于 SimpleCNN 的读出（43.3）**，配对错误完全可能发生。
   → **建议**：把三条虚线分别按对应实线的颜色画成**同色细点线**（取代统一灰色），或在每条虚线右端加 `SC / VGG / RN` 小标签。
2. **（中）没有误差棒**；而深层主干的种子标准差（±3.18 / ±3.40）是全文最大的，图上只在 α=+0.3 **一个点**用文字标注。图注虽已说明，但读者看到的三条平滑曲线会低估不确定性。
   → **建议**：给三条实线加 ±1 SD 阴影带（数据已在 CSV 里，零成本）。
3. **（低）**三个 ±标注画在坐标框**外侧**（`xytext=(4,4)` + x=0.3），贴着图右缘，最后一个与边框相撞。
