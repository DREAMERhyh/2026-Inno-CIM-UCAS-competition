## 2. 🔴 头号问题：系统内存枯竭（本版新增，最重要）

**症状**：M4 训练报 `CUDA error: out of memory`，**但显存空着 7 GB**（实测 8188 MiB 总量、只用 3.8 GB）。

**根因**：**不是 VRAM，是系统内存 / WDDM 分配失败。** 崩溃时 free physical 0.6 GB、commit 1.46 GB。

**实测水位**：物理总量 15.7 GB。大占用者：**VS Code 5.2 GB**（Claude 会话在其中，**不能关**）、
训练 ~6 GB、用户程序（WPS / SpaceSniffer / Wallpaper Engine / PowerToys / Edge）。
⚠ **6 个 Claude 会话工作组合计只有 664 MB —— 不是压力源**（一个被实测推翻的假说，见坑表）。

**⇒ 已上报用户，请其关闭不用的程序。** 用户未关之前：
- **任何吃内存的活之前先量余量**
- **⚠ 赌注不对称**：Windows 提交内存是**全局**的，你的进程吃掉的余量会让**训练**的下一次分配失败
  —— **打死的是训练，不是你的脚本**

⚠ 这个数**被低估过三次**，每次都是同一个错——**拿"训练吞吐"当"epoch 时间"**。

### 守护进程 v2（**本版重点，v1 有会毁掉整个 M4 的缺陷**）

**v1 的缺陷**：把"训练进程退出"当成"跑完了"——**崩溃也会让进程退出**。实测后果：
```
16:37:26  launching seed 43
16:44:11  seed 43 finished        ← 只过了 6 分 45 秒！
16:44:11  launching seed 44       ← 丢下 seed 43、直接推进
```

**v2 的四处修改**（`tools/v7_m4_watchdog.ps1`）：
1. **完成判据只认产物**：`metrics.json` 存在 **且 `total_epochs` 等于预期**（120 / 200）
2. **launch 返回后重新查产物**：不在 ⇒ 判为崩溃，**`break`，不推进到下一个 run**
3. **连续崩溃指数退避**（120·2^(n−1)，上限 1800 s）
4. **内存闸门**：free physical < 1500 MB 就不拉起，每 5 分钟重查

**v2 一启动就证明修对了**：首行 `waiting (training pid 36656 alive; **2 run(s) left**)`
—— 正确认出 s43 也缺（v1 会误判它已完成）。

**启动坑（都实测踩过）**：
- **反引号续行 + LF 行尾 ⇒ ParserError，进程秒退**（已改 CRLF、不用续行）
- **不要用 `-ExecutionPolicy Bypass`**：本机 CurrentUser = `RemoteSigned`，本地脚本本来就能跑；
  用那个参数**会无故削弱一道安全控制**（且被权限系统拦下——拦得对）
- **脚本必须纯 ASCII**：PS 5.1 读无 BOM 的 UTF-8 `.ps1` 会按 ANSI 解码，中文路径读成乱码
  ⇒ 所有路径从 `$PSScriptRoot` 推导

## 7. 🔴 本阶段的主导病因：**跨数据集 / 跨口径"搬数"**

**一天内抓到 ≥4 次同形**：A6（dithering 机理数全是 C10 的）、「100ep」、`0.933`、以及更早的
A3（同表三行不同主干实例）、E4（48.35 vs 48.25 的差是**设备口径** cuda vs cpu）、
E7（`0.39062` 被误判为笔误，实为另一条合法产物）。

> **数字的可追溯性很好。坏的是"数的定语没跟着搬"——哪个数据集、哪个主干、哪个协议、哪个设备。**

**改一个数之前先问三句**：**这是哪个数据集？哪个主干实例？哪个协议/设备？**
**见到"同一个量有两个值"，先查是不是两个产物，别默认其中一个错。**

## 8. 八条最容易踩的（都实测踩过）

1. **markdown 写进 LaTeX**（累计 **11 次**）——`**粗体**` / 反引号 / 行首 `>` 都是**静默失效**。
   ⇒ 改完必跑 `tools/check_papers.py`，别靠记性。
2. **台账只能一个写者**——**"写入"包括改头部注记**。对象是**文件**，不是文件里某一段。
3. **设备口径也是口径**——CPU 与 CUDA 的读数不可混。
4. **🔴 不要用 `-ExecutionPolicy Bypass`**（本机 RemoteSigned，不需要；且会无故削弱安全控制）。
5. **🔴 本地 PS 脚本别写中文 + 别用反引号续行**（PS 5.1 + 无 BOM UTF-8 + LF ⇒ 乱码 / ParserError）。
6. **行号在本仓库极不可靠**（journal 一天内 1258 → 1442 → 26 页）。
   ⇒ **引用位置一律附原文字符串**，行号只作辅助。
7. **"it/s" 不是 "epoch 时间"**——M4 的耗时被这个错低估了**三次**。
8. **GPU 利用率必须连采**（`3 2 0 3 3 3 87 96`：单次会骗人）。
   **判断"训练在不在干活"要看产物 mtime，别只盯日志或单次 GPU 读数。**
