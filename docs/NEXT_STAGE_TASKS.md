**Central Claim（一句话，后续一切以它为判据）**：

> 在三次多项式逐层非线性失真下，灾难尾（$\alpha=+0.3$）损失的是**读出的可解码性**而非表征中的信息；
> 因此冻结全部模拟权重、只重训最后的线性层，可在 1/15~1/30 的成本下超过任何全网络鲁棒训练配方；
> 且该收益与一个独立的架构杠杆（池化降维）在尾部可叠加；而训练端的四条补救路径全部失效。

**已知未知（不许当结论用）**：跨训练实现的 5.55 pp 稳定差异，三次归因（种子噪声 → 采样粒度 → RNG 消耗数）全部失败，按 known-unknown 记录。

## 1. 红线（不可违反，逐条都有事故来源）

1. **eval 语义不可动**：全量测试集（10\,000）+ best 权重 + 纯推理 + 七点（或 15 点）协议；
   每个 run 的 `alpha_sensitivity.csv` 里 $\alpha=0$ 行必须等于同目录 `metrics.json` 的 `best_test_acc`（容差 0.01）。
2. **训练严格串行**。项目出过三次事故（一次 CUDA OOM，两次 Windows 提交内存耗尽 error 1455）。
   本机是 4070、显存比历史假设宽裕，**但并行必须先小规模验证再放开**，不得直接并发。
3. **产物零覆盖**。新产物一律带后缀（`_s43` / `_v7` / `_tag`）；跑前核验目标目录不存在。
4. **判据跑前写死，跑后不改**。每个实验动手前先在台账登记判据；跑完立即追加结果 + 判决 + commit。
5. **降级一个数字，必须扫它的整条引用链**（含均值、差值、占比这些派生量——它们不带原值，grep 抓不到）。
6. **分级词汇不许升格**：初步 / 提示性 / 不可分辨 / 已知未知，逐字保留。
7. **跨训练实现的精度数字不可混用**（`task2_nat.py` 与 `v3_methods_simplecnn.py` 稳定差 5.55 pp）。
8. **代码改动默认行为不变**：任何新开关跑前冒烟验证"默认路径与改造前逐位一致"。

### 阶段二：把结论钉死（GPU ≈30 h）

#### M4　深层主干方差 ★（≈16 h）
- **动作**：VGG-11（Exp2 配方）与 ResNet-18（Exp3 配方）各重训 **2 个 seed**（200ep），产物带 `_s43/_s44`。
  然后重训读出适配（3 seed）→ 重算尾部与 clean 的**主干级方差**。
- **为什么**：**这是唯一一条可能让 Central Claim 需要收缩的实验**。
  核心数字（VGG-11 47.79±3.18、ResNet-18 26.82±3.40）里，**主干那一份方差至今没测过**；
  而已知固定主干上换读出种子，ResNet-18 的 clean 就能从 63.54 摆到 67.61（±1.85）。
- **判据（跑前写死）**：
  | 分支 | 条件 | 判决 |
  |---|---|---|
  | ① | 主干级标准差 **≤1.5 pp** | Central Claim 锁定，可写"跨主干种子稳健" |
  | ② | **1.5~3 pp** | 合格但需在论文加条件（"在已测主干上成立"） |
  | ③ | **≥3 pp** | **触发止损线 1** —— 「读出适配超过全网络配方」这句在深层上要收缩，立即停下报告 |
- **交付**：台账 §16.1（四段式）+ 论文相应数字的置信区间更新。

#### M5　秩-恢复曲线的形状（≈2 h）
- **动作**：补第 **4 个容量档**的秩-恢复点（选一个介于 SimpleCNN 与 ResNet-18 之间的主干）。
- **为什么**：现三点 $r=-0.960$，但形状提示"先平后塌"（前两点只差 2.0，第三点低 33.3）。三点定不了形状。
- **判据**：四点能否判定形状（线性 / 有阈值 / 折线）；若能，给出经验关系或阈值；不能则如实写"仍不足以判定"。

#### M6　L8 两成分分解（≈10 h）
- **动作**：**换效应量更大的对照**——池化窗口 $2\times2$ vs $4\times4$，或池化层的位置分布；而不是继续给 avg/max 加种子。
- **为什么**：avg 与 max 的差距只有 +1.17 pp（SE 1.03，$z\approx1.1$），**是那条路的根本瓶颈**。
- **判据**：新对照的效应量 **≥3 pp** 才算有分辨力；据此裁决"降维 : 非聚合"的定量比例。
  若新对照的效应量仍 <3 pp，如实写"该路线的根本限制是效应量本身太小"。

#### M7　5.55 pp 的机制（≥2 次训练 + 人工）
- **动作**：**逐行对齐两个训练循环做二分**（换评估路径已验证无效，必须动训练循环）。
- **判据（前置，跑前写死）**：**必须能解释「同脚本换 seed 只值 ±1、跨脚本却稳定 5.55」这个量级差**；

### 阶段三：打开新问题（**研究核心**，按"能否打开新问题空间"排序）

#### M8　读出的上界在哪？（≈10 h）
- **问题**：**线性探针给出的 47.89% 是不是天花板？非线性读出能走多远？**
- **动作**：在同一冻结主干上比较读出容量族：线性头 / 瓶颈 MLP / 两层 MLP / k-NN / 逻辑回归（不同正则）。
  已有 `d_dist_fit_mlp` 这一臂可作起点，但需补齐**同口径**的容量阶梯。
- **为什么重要**：Central Claim 依赖"信息仍线性可达"，但**从未测过非线性读出的上界**——
  如果 MLP 头能到 70%，那"读出瓶颈"的说法要改成"线性读出的瓶颈"，结论会更强也更准。
- **判据**：给出"读出容量 → 可恢复率"的曲线；若能显著超过线性上界，则改写 L6 的表述。

#### M9　用表征几何预测可恢复性（≈6 h，多为纯前向）
- **问题**：**秩损失能预测可恢复量，那还有没有更好的预测量？**
- **动作**：在同一批冻结特征上，同时计算：有效秩、参与比、99% 条件数、类间/类内散布比、
  Fisher、有效维度（PR）、以及**缺失子空间与被删类的对应关系**。与实测恢复率做相关。
- **为什么重要**：M5 只能给形状，M9 可能给出**一个可计算的预测器**——这会把 L4 与 L6 真正接起来。
- **判据**：找出与恢复率 $|r|>0.95$ 的几何量；若无，如实记录"秩是已知最好的单变量预测器"。

#### M10　恢复率的标度律（≈8 h）
- **问题**：**恢复率随任务难度缩放**（C10 83.0/86.4/34.3 % vs C100 68.6/59.8/22.6 %）——这是两点连线，第三点在哪？
- **动作**：引入**第三个难度档**（推荐 CIFAR-100 的 superclass 20 类版本，或 TinyImageNet 子集），跑同一套三主干 + 读出适配。
- **判据**：三点能否给出"任务难度 → 恢复率"的单调关系；若能，拟合一个**单参数**的经验式（不许上多参数模型）。

#### M11　多头扩展：α̂ + σ̂ 三头路由（≈6 h）
- **问题**：**双扰动并存时的最优调度是什么？** 已知 σ-only 训练最优（24.60），但那是"训练端选择"，不是"调度"。
- **动作**：数据集已有（joint / σ-only 两组权重）。加第三个头（高斯鲁棒）+ σ̂ 估计器（特征 → σ 的岭回归），
  做三元调度（clean / α-robust / σ-robust），与 σ-only、joint、oracle 比。
- **判据**：三头调度能否超过 σ-only 基线；若不能，如实记"多头调度的收益被训练端的通路干扰吃掉了"。

#### M12　门控机制：为什么插值能超过 oracle？（≈0 GPU，纯分析 + 少量重跑）
- **问题**：软门控在 CIFAR-100 上 3/7 个点超过"逐点选优"的 oracle、CIFAR-10 上只有 1/7——**这个差异从哪来？**
- **动作**：把"插值即集成"这个曾撤回的主张重新拆开——**集成的收益应当来自两个头的误差负相关**。
  直接测两个头在各 α 点的**逐样本预测相关性**与**错误重叠率**。
- **为什么重要**：这是项目里**唯一一条被撤回的强主张**（P0-C 未复现）。搞清它，要么恢复、要么永久关闭。
- **判据**：若两头错误的负相关在 CIFAR-100 上显著高于 CIFAR-10 → 给出机制解释并恢复有条件的主张；否则永久关闭。

#### M13　失真形态族下的 headroom（≈12 h）
- **问题**：**当前全部结论都建立在三次多项式这一族上——换形态会怎样？**
- **动作**：构造形态族（都保持"确定性 + 输入相关 + 逐层"三个性质）：更高阶项（$x^5$）、
  非对称系数（正负不同 $\alpha$）、加性偏置、器件失配的乘性随机成分（固定种子）。测 headroom 与读出杠杆。
- **判据**：headroom 对形态的敏感性；已知下界是加性高斯噪声（+7.00 vs 非线性 +20.12）。
  **这是把结论从"这一族"推广到"这一类"的关键一步。**

#### M14　零成本架构杠杆的系统搜索（≈10 h）
- **问题**：池化**密度**是杠杆，那池化的**窗口大小 / 位置分布 / 主干宽度**呢？
- **动作**：在参数量不变的前提下扫：池化窗口（$2\times2$ / $3\times3$ / $4\times4$）、
  池化位置（前置 / 后置 / 均匀）、主干宽度（通道数重分配）。
- **判据**：找出效应量 **≥3 pp** 的杠杆（M6 的经验：<3 pp 的效应在 seed 噪声内无法裁决）；
  并检查它们与已知两个杠杆（读出、池化密度）是否正交。
