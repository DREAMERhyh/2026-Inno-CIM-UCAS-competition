# Task1 总结 — SimpleCNN @ CIFAR-100：非线性失真 α 敏感性分析

## 1. 实验设置

| 项目       | 内容                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| 模型       | SimpleCNN（4×conv + fc，输出 100 类）                                                                           |
| 干净权重   | `checkpoints_cifar100/simple_cnn/best_model.pth`，best_test_acc = **59.99%**（epoch 114/120）                   |
| 评估数据   | CIFAR-100 测试集 10,000 张（全量）                                                                              |
| α 网格     | {−0.3, −0.2, −0.1, 0.0, +0.1, +0.2, +0.3}，非线性失真（幅值缩放 + 噪声），全部观测层同时注入                    |
| 层分析协议 | 固定 500 张样本，观测 conv1/conv2/conv3/conv4/fc 共 5 层输出；指标：RME（幅值相对偏移）、余弦相似度（方向保持） |
| 产物目录   | `outputs_cifar100/task1_simple_cnn/`                                                                            |

**一致性核对**：α=0 精度 59.99 与 metrics.json 的 best_test_acc 完全一致；α=0 loss 1.4958 与 final_test_loss 1.4941 吻合。✓

## 2. 整网精度扫描

| α    | CIFAR-100 Acc | Δ(pp)  | 相对跌幅 | CIFAR-10 Acc | Δ(pp)  | 相对跌幅 |
| ---- | ------------- | ------ | -------- | ------------ | ------ | -------- |
| −0.3 | 42.91         | −17.08 | 28.5%    | 76.06        | −8.84  | 10.4%    |
| −0.2 | 51.14         | −8.85  | 14.8%    | 79.99        | −4.91  | 5.8%     |
| −0.1 | 57.22         | −2.77  | 4.6%     | 83.26        | −1.64  | 1.9%     |
| 0.0  | **59.99**     | 0      | 0        | 84.90        | 0      | 0        |
| +0.1 | 58.09         | −1.90  | 3.2%     | 82.66        | −2.24  | 2.6%     |
| +0.2 | 47.62         | −12.37 | 20.6%    | 73.50        | −11.40 | 13.4%    |
| +0.3 | 28.09         | −31.90 | 53.2%    | 55.08        | −29.82 | 35.1%    |

**关键发现**：

1. **α=0 即峰值，安全平坦区 |α|≤0.1**：跌幅 ≤2.77pp（≤4.6%），模型对弱失真近乎无感；不存在"非零 α 更优"的情况。
2. **陡降肩部位于 |α|∈[0.1, 0.2]**：+0.2 时已损失 12.37pp（相对 20.6%）。
3. **|α|=0.3 正方向崩塌**：精度 28.09%，相对跌幅 53.2%，可用精度只剩干净基线的一半略多（仍远高于 1% 随机水平）。
4. **正负不对称，正方向（压缩）更伤**：|α|=0.3 时 +31.90pp vs −17.08pp（约 1.9 倍）；该不对称随强度增大而显现（|α|=0.1 时基本对称，−0.1 甚至略更伤）。

## 3. 逐层分布偏移分析

最强扰动 |α|=0.3 时各层指标（RME / 余弦相似度）：

| 层    | α=+0.3             | α=−0.3         |
| ----- | ------------------ | -------------- |
| conv1 | 0.136 / 0.9926     | 0.136 / 0.9958 |
| conv2 | 0.337 / 0.9937     | 0.399 / 0.9965 |
| conv3 | 0.429 / 0.9340     | 0.932 / 0.9527 |
| conv4 | 0.619 / 0.7933     | 0.937 / 0.8783 |
| fc    | 1.023 / **0.6919** | 1.574 / 0.8822 |

**关键发现**：

1. **误差随深度单调累积**：RME 逐层递增、余弦相似度逐层递降；最敏感层 = fc（+0.3 时 cos 仅 0.692），最稳健层 = conv1（≥0.993）。
2. **conv1–conv2 构成"稳定高原"**：全部强度下 cos ≥ 0.993，损伤集中在 conv3 之后。直方图佐证：conv1 分布形态基本不变；conv4 在 α=+0.3 下显著变尖变窄（峰值密度约 1.8→3.6，激活向零收缩），形变远比 conv1 剧烈。
3. **方向破坏比幅值偏移更能解释精度损失（本任务最重要的机制发现）**：α=−0.3 的 RME 全面高于 +0.3（fc 层 1.574 vs 1.023），精度却更高（42.91% vs 28.09%）；而 fc/conv4 的余弦相似度与精度在 7 个测点上高度相关（近乎单调）。即：幅值被推移不致命，**深层表征方向被破坏才是掉点的载体**。
4. **正负 α 的层级模式不同**：−0.3（放大）使 conv3/conv4 幅值偏移最重（RME≈0.93 持平）但 fc 方向保持较好（cos 0.882）；+0.3（压缩）的破坏一路穿透到 fc（cos 0.692）——与精度上正方向更伤一致。
5. **度量口径提醒**：RME 分母为 clean 层输出均值范数，对均值≈0 的层（conv1）会被微小均值漂移放大——conv1 的 RME 0.136 看似不小，但直方图与 cos 表明其形态几乎未变。跨模型比较建议以 cos 为主、RME 为辅。

## 4. 与 CIFAR-10 对比（同模型、同协议）

1. **定性结论全部迁移**：平坦区→肩部→崩塌的三段结构、正 α 更伤、误差随深度累积、浅层稳深层脆——在 100 类下逐条复现。方法学结论对数据集规模稳健。
2. **绝对跌幅几乎相同，相对脆弱性显著更高**：+0.2 时 −11.40 vs −12.37pp，+0.3 时 −29.82 vs −31.90pp——"每单位 α 的绝对代价"与类别数基本无关；但相对跌幅 35.1% vs 53.2%。差别在起点：59.99% 的起点让同样的绝对损失吃掉更大比例的可用精度。
3. **崩塌阈值更早**：CIFAR-100 在 α=+0.3 已跌破干净基线一半（28.09 < 30.0）；CIFAR-10 同强度仍保有 clean 的 65%。
4. **负方向容忍度差异（待验证观察）**：α=−0.3 时 CIFAR-10 仅跌 10.4%（相对），CIFAR-100 跌 28.5%——100 类模型对幅值放大的缓冲更小，可能与深层表征冗余更少有关，单次实验不足以定论，记录备查。

## 5. 结论与对后续任务的启示

1. **最优工作区**：α=0 附近，|α|≤0.1 为安全平坦区。task2/task3 沿用 {0.1, 0.2, 0.3} 强度点，恰好覆盖平坦→肩部→崩塌的完整动态范围，与 CIFAR-10 协议对齐。
2. **NAT 训练（task2）应确保正 α 区域覆盖充分**——压缩方向是更强的"对手"。
3. **脆弱核心在 conv3→fc 深层通路，且方向破坏是精度损失的载体**——为 task3 分层差异化 α（Exp2）提供直接动机：对深层施加更强的稳定性约束；同时提示"仅校准"（主要作用于幅值/分布层面）的收益可能有限，需与"校准+分层 α"对比验证。
4. **跨数据集报告规范**：CIFAR-100 上所有"鲁棒性提升 x pp"应同时报告相对值（%）——机制不变，但安全边际变小，绝对值与相对值的结论可能出现不同侧重。
