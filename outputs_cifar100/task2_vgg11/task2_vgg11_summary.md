# Task2 总结 — VGG-11 @ CIFAR-100：NAT（随机 α）训练的鲁棒性代价与收益

## 1. 实验设置

| 项目     | 内容                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------- |
| 训练范式 | NAT：训练时 α ~ U(−0.3, +0.3) 随机注入非线性失真                                                                          |
| 两种模式 | scratch（随机初始化，200 epochs）/ finetune（从 clean 基线 `checkpoints_cifar100/vgg11/best_model.pth` 起步，200 epochs） |
| 对照基线 | task1 的 clean VGG-11：clean acc **67.09%**（best@193）                                                                   |
| 评估协议 | 与 task1 完全一致：全量测试集、α 网格 {−0.3,…,+0.3}、best 权重复评                                                        |
| 产物目录 | `outputs_cifar100/task2_vggcnn/`（scratch 与 finetune 分目录）                                                            |

**数据配对核查**：metrics 上传顺序与标注相反（首份实为 scratch），但 CSV α=0 复评值可自识别（67.12 ↔ finetune best、67.25 ↔ scratch best），且与此前目录扫描逐位一致，配对无疑义。✓

**一致性核对**：scratch CSV α=0 = 67.25 = best_test_acc ✓；finetune CSV α=0 = 67.12 = best_test_acc ✓。

## 2. 训练动态与干净精度

| 指标                      | clean 基线 | NAT-scratch | NAT-finetune |
| ------------------------- | ---------- | ----------- | ------------ |
| best_test_acc (%)         | 67.09      | **67.25**   | 67.12        |
| best_epoch                | 193/200    | 188/200     | 168/200      |
| final train/test gap (pp) | 33.1       | 34.1        | 34.6         |
| clean loss (α=0)          | 1.564      | 1.587       | 1.550        |

1. **clean 精度不降微升**（+0.16 / +0.03 pp）："clean 无损"观察在第二个架构上复现；且 scratch 的 67.25 为全部 VGG 权重（clean/scratch/finetune）中最高。
2. **NAT 未缓解 VGG 的过拟合**：两种模式 final_train_acc 仍达 99.97%，gap 反而略增（33.1 → 34.1/34.6pp）——鲁棒性收益并非来自正则化，而是模型在保持 clean 能力的同时额外学会了失真不变性（容量余量的作用，见 §5）。
3. 达峰后均有轻微回落（scratch 67.25→65.84，finetune 67.12→65.37）；scratch 的 best@188 逼近训练末端，"更长 schedule 或有余量"的观察再次出现。

## 3. 鲁棒性扫描：核心发现是"全轴正增益"

| α    | 基线  | NAT-scratch | Δ         | NAT-finetune | Δ     |
| ---- | ----- | ----------- | --------- | ------------ | ----- |
| −0.3 | 24.48 | 34.07       | **+9.59** | 25.21        | +0.73 |
| −0.2 | 43.28 | 50.15       | +6.87     | 43.52        | +0.24 |
| −0.1 | 60.14 | 62.01       | +1.87     | 59.84        | −0.30 |
| 0.0  | 67.09 | 67.25       | +0.16     | 67.12        | +0.03 |
| +0.1 | 60.94 | 62.95       | +2.01     | 62.46        | +1.52 |
| +0.2 | 39.05 | 45.04       | +5.99     | 42.91        | +3.86 |
| +0.3 | 16.92 | 21.89       | **+4.97** | 19.80        | +2.88 |

**关键发现**：

1. **【头条】与 SimpleCNN 的"方向再分配"质变不同，VGG-11 的 NAT 是全轴普惠型改善**：scratch 在 7/7 测点为正，finetune 6/7 为正（唯一负值 −0.30pp 在单种子噪声量级）。**没有出现 SimpleCNN 式的"+α 尾部恶化"**——对称随机 α 训练在这两个架构上产生了质上不同的收益结构。
2. **Δ 轮廓与基线脆弱度大体同形**：基线跌幅越大的强度点收益越大（负侧严格单调：+9.59 → +6.87 → +1.87；正侧 +5.99@0.2 → +4.97@0.3 轻微饱和）。NAT 的收益自动集中在基线最脆弱的区域。
3. **恢复率量化**（Δ ÷ 基线跌幅）：scratch 在 |α|≤0.2 各点恢复 21%~33% 的基线损失，但 **+0.3 极端点仅恢复 9.9%**（4.97/50.17）——最深的坑最难填，压缩崩塌区仍是残余短板。
4. **相对跌幅收窄但不对称性走向分化**：+0.3 相对跌幅 74.8% → 67.5% (scratch) / 70.5% (finetune)；−0.3 相对跌幅 63.5% → **49.3% (scratch)** / 62.4% (finetune)。|α|=0.3 正/负绝对跌幅比：基线 1.18× → scratch **1.37×**（负侧受益更多、不对称扩大）vs finetune **1.13×**（正侧受益更多、不对称收窄）——两种模式的 Δ 轮廓互为镜像。
5. **loss 与精度一致**：−0.3 的 loss 基线 9.68 → scratch 6.94（−28%）vs finetune 8.83（−9%），与 scratch 在负侧的更大增益吻合。

## 4. scratch vs finetune

1. **scratch 在全部 7 个测点胜出**（差距：+8.86 / +6.63 / +2.17 / +0.13 / +0.49 / +2.13 / +2.09）——与 SimpleCNN 的"平手"不同，这是第二个模型上 scratch ≥ finetune，且这次是全面胜出（单种子证据，定论仍需多种子，但方向一致性强）。
2. 两种模式的收益定位互补：scratch 主攻负向（放大）侧，finetune 主攻正向（压缩）侧（+0.2 处 +3.86 为其最大收益点）。若追求压缩尾部，finetune 是唯一有正收益定位的模式——但其总收益仍全面小于 scratch。
3. **成本侧 scratch 再次占优**：200 epochs vs 隐含 400（基线 200 + finetune 200）。**scratch 为 VGG-11 的默认推荐**。

## 5. 跨模型对比与机制假设（SimpleCNN vs VGG-11，task2 行为分岔）

| 维度                 | SimpleCNN（0.24M）                   | VGG-11（9.2M）            |
| -------------------- | ------------------------------------ | ------------------------- |
| Δ 轮廓               | 单调递减：−α 正、+α 负（**再分配**） | **全轴正**（scratch 7/7） |
| +0.3 变化            | −6.68 / −3.28（恶化）                | +4.97 / +2.88（改善）     |
| −0.3 变化            | +3.29 / +2.88                        | +9.59 / +0.73             |
| clean 变化           | +0.71 / +0.17                        | +0.16 / +0.03             |
| scratch vs finetune  | 平手（互有胜负）                     | scratch 全 7 点胜         |
| task1 train/test gap | 13.8pp                               | 33.1pp                    |

**候选机制假设（待检验）**：

- **H-capacity（容量/过拟合余量假说）**：NAT 收益结构由模型的容量余量决定。VGG 重度过拟合（gap 33pp）、参数冗余大，存在"免费的"表征容量同时容纳 clean 能力与失真不变性 → 全轴受益；SimpleCNN 余量小（gap 14pp），鲁棒性改进受守恒式约束，−α 的收益以 +α 为代价 → 再分配。**可检验预测**：ResNet-18（gap 28pp，居中）应呈"以正增益为主、可能带轻微正向应力"的中间形态；若成立，gap 与再分配幅度应跨三模型单调。
- **H-fragility（脆弱模式耦合）**：task1 已确认 SimpleCNN 的 +α 是断崖式崩塌（深层方向被摧毁），对称采样的 NAT 无法修复而反受其害；VGG 的损伤双侧均匀且相对温和，对称暴露即可双侧改善。该假设与 H-capacity 不互斥，可能共同作用。
- 两模式 Δ 镜像（scratch 偏负侧、finetune 偏正侧）的机制**开放**，记录备查。

## 6. 对后续任务的启示

1. **ResNet-18 task2（材料已就绪）是分岔假说的裁决点**：重点看 Δ 轮廓属"再分配"还是"全轴正"，及其与 gap（28pp）的对应关系。
2. **ext6 的门槛提高了**：plain NAT-scratch 已把 VGG +0.3 从 16.92 抬到 21.89（恢复基线损失的 ~10%）——Exp2（校准+分层 α）必须显著超过 21.89 才能证明其复杂度合理；ext6 训练时每 epoch 记录的 α=+0.3 精度可与该值直接对标。
3. **task3 非对称采样（70% 正向）的动机转移**：SimpleCNN 的压缩尾部需要非对称采样救场；VGG 的 +α 尾部恢复率仅 ~10%，若 resnet18 复现此模式，"偏斜采样修补极端压缩区"可作为 task3 深层版（ext6 后续变体）的正式假设。
4. scratch 作为默认训练模式的结论在第二个架构上加固（性能与成本双优）。
