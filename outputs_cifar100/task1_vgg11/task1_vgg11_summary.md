# Task1 总结 — VGG-11 @ CIFAR-100：非线性失真 α 敏感性分析

## 1. 实验设置

| 项目       | 内容                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------- |
| 模型       | VGG-11（features 四个 block + classifier，输出 100 类）                                  |
| 干净权重   | `checkpoints_cifar100/vgg11/best_model.pth`，best_test_acc = **67.09%**（epoch 193/200） |
| 评估数据   | CIFAR-100 测试集 10,000 张（全量）                                                       |
| α 网格     | {−0.3, −0.2, −0.1, 0.0, +0.1, +0.2, +0.3}，全部观测层同时注入                            |
| 层分析协议 | 固定 500 张样本，观测 block2/block3/block4/block5/fc 共 5 层输出；指标：RME、余弦相似度  |
| 产物目录   | `outputs_cifar100/task1_vgg11/`                                                          |

**一致性核对**：α=0 精度 67.09 与 metrics.json 的 best_test_acc 完全一致；α=0 loss 1.5639 与 final_test_loss 1.5640 吻合。✓

**训练动态备注**：final_train_acc 99.97% vs final_test_acc 66.88%（gap 33.1pp，train loss 0.0036）——VGG-11 在 CIFAR-100 上**明显过拟合**（容量大于任务需求）。这是训练侧观察，不影响推理时扰动结论，但记入跨模型分析备查（SimpleCNN 同设置 gap 仅 13.8pp）。

**复现备注**：层分析 CSV 为修复观测层顺序列表（追加 fc_output）后重新生成；block2~block5 各行与首次运行逐位一致（seed=42 确定性），修复为纯增量，未影响任何已有数值。

## 2. 整网精度扫描

| α    | CIFAR-100 Acc | Δ(pp)  | 相对跌幅 | CIFAR-10 Acc | Δ(pp)  | 相对跌幅 |
| ---- | ------------- | ------ | -------- | ------------ | ------ | -------- |
| −0.3 | 24.48         | −42.61 | 63.5%    | 51.83        | −37.97 | 42.3%    |
| −0.2 | 43.28         | −23.81 | 35.5%    | 72.76        | −17.04 | 19.0%    |
| −0.1 | 60.14         | −6.95  | 10.4%    | 85.22        | −4.58  | 5.1%     |
| 0.0  | **67.09**     | 0      | 0        | 89.80        | 0      | 0        |
| +0.1 | 60.94         | −6.15  | 9.2%     | 85.65        | −4.15  | 4.6%     |
| +0.2 | 39.05         | −28.04 | 41.8%    | 66.83        | −22.97 | 25.6%    |
| +0.3 | 16.92         | −50.17 | 74.8%    | 36.70        | −53.10 | 59.1%    |

**关键发现**：

1. **α=0 即峰值**，无"非零 α 更优"，与 SimpleCNN 一致。
2. **安全平坦区明显更窄**：|α|=0.1 已损失约 10% 相对精度（SimpleCNN 同强度仅 3~5%）；三段式"平坦→肩部→崩塌"结构保持，但整体**左移、变陡**——肩部从 |α|≈0.2 提前到 |α|≈0.1。
3. **|α|=0.3 双向崩塌，正方向更狠**：+0.3 仅剩 16.92%（相对损失 74.8%），−0.3 剩 24.48%（63.5%）——**两个方向都跌破干净基线的一半**（CIFAR-10 上只有正方向跌破一半）。
4. **正负不对称性显著弱于 SimpleCNN**：|α|=0.3 时正/负跌幅比仅 1.18×（SimpleCNN 为 1.87×；CIFAR-10 上 VGG 1.40× vs SimpleCNN 3.37×）。即：**SimpleCNN 对幅值放大有较好容忍、对压缩敏感；VGG-11 对两个方向都近乎对称地脆弱**。
5. **loss 爆炸更剧烈**：−0.3 时 loss 9.68，为 clean 的 6.2 倍（SimpleCNN 同点仅 2.25 倍）。

## 3. 逐层分布偏移分析

各层平均余弦相似度（跨 α≠0 平均）：block2 0.9735 > block3 0.9364 > block4 0.8837 > block5 0.8370 > **fc 0.6611**。

最强扰动 |α|=0.3 时各层指标（RME / cos）：

| 层     | α=+0.3             | α=−0.3         |
| ------ | ------------------ | -------------- |
| block2 | 0.292 / 0.9431     | 0.355 / 0.9575 |
| block3 | 0.414 / 0.8798     | 0.545 / 0.8846 |
| block4 | 0.597 / 0.7459     | 1.039 / 0.8373 |
| block5 | 0.500 / 0.7242     | 1.132 / 0.7499 |
| fc     | 2.491 / **0.4380** | 8.146 / 0.4078 |

**关键发现**：

1. **最敏感层 = fc（分类头），且梯度最陡**：平均 cos 0.661，比 block5（0.837）低 0.176；误差累积沿深度单调下降，block5→fc 是最陡一跳（+0.3：0.724→0.438；−0.3：0.750→0.408）。最稳健层 = block2。与 SimpleCNN 的"fc 最敏感"模式一致——**"损伤终点在分类头"跨模型成立**。
2. **"方向破坏载体"机制：同号方向内完美成立**。fc 的 cos 与精度在两个方向上各自严格单调共变：

   | α    | Acc (%) | fc cos | fc RME | block5 cos |
   | ---- | ------- | ------ | ------ | ---------- |
   | −0.3 | 24.48   | 0.4078 | 8.146  | 0.7499     |
   | −0.2 | 43.28   | 0.6435 | 4.259  | 0.8399     |
   | −0.1 | 60.14   | 0.8922 | 1.687  | 0.9428     |
   | +0.1 | 60.94   | 0.9025 | 1.124  | 0.9396     |
   | +0.2 | 39.05   | 0.6826 | 1.955  | 0.8254     |
   | +0.3 | 16.92   | 0.4380 | 2.491  | 0.7242     |

   负侧 cos 0.892→0.644→0.408 对应精度 60.14→43.28→24.48；正侧 0.903→0.683→0.438 对应 60.94→39.05→16.92——两侧均严格单调。整体秩相关：fc ρ≈0.89、block5 ρ≈0.94，cos 仍是精度损失的最佳预测指标。
3. **跨符号比较出现新细节（记录备查）**：|α|=0.2/0.3 时，fc 的 cos 排序（负 α 更低）与精度排序（正 α 更差）**相反**；block5 的 cos 排序与精度一致（仅 |α|=0.1 一处 0.003 的微弱反向）。提示：跨符号比较时，**特征阶段（block4/block5）的方向比 logits 层的方向更稳地预测精度**——fc/logits 的 cos 混入了读出层自身畸变的几何（logits 均值范数小、对加性畸变敏感）。机制解释待深究（可查 `utils/nonlinearity.py` 的注入形式），不影响主结论。
4. **RME 脱钩在 fc 极端化**：−0.3 的 fc RME 高达 8.15（全表最大），精度却好于 +0.3（RME 仅 2.49）——RME 分母效应（logits 均值范数极小）与"幅值/方向脱钩"双重体现。**fc 的 RME 不具跨层可比性**；结合 block 层的持续反向（−0.3 全面高于 +0.3、精度却更好），跨层比较应以 cos 为唯一主指标，RME 仅作参考。
5. **直方图佐证"压缩向零集中、随深度放大"**：VGG 各 block 输出为 ReLU 后非负、零点重质分布。α=+0.3 下 block2 分布几乎不变（零点峰 3.7→3.75）；block5 零点峰密度 1.53→2.30（+50%）、右尾缩短——激活向零收缩的形变随深度显著放大，与 cos 递降一致。

## 4. 与 CIFAR-10 对比（同模型、同协议）

1. **定性结论全部迁移**：α=0 峰值、三段结构、正方向更伤、误差随深度累积、cos 主导精度损失——逐条复现，方法学结论再次跨数据集稳健。
2. **相对脆弱性显著更高**：+0.3 相对跌幅 74.8% vs 59.1%；且 CIFAR-100 上**负方向也崩塌**（跌破一半），CIFAR-10 不会。
3. **绝对跌幅量级仍接近**：+0.3 时 −50.17 vs −53.10pp（CIFAR-10 甚至略大），延续"每单位 α 的绝对代价与类别数基本无关"的观察；差异主要体现在起点精度与相对占比。
4. **跨模型对比（ext1 预告点）**：VGG-11 在两个数据集上都比 SimpleCNN 脆弱得多（+0.3 相对跌幅：CIFAR-100 74.8% vs 53.2%；CIFAR-10 59.1% vs 35.1%），且对称性更强、loss 爆炸更狠、过拟合更重——"容量更大 ≠ 扰动下更稳"的跨模型结论已在两个数据集上同时成立。resnet18 数据到位后可完成三方排序。

## 5. 结论与对后续任务的启示

1. **α 网格 {0.1, 0.2, 0.3} 依旧覆盖平坦→肩部→崩塌全动态范围**，协议不变；但 VGG 的平坦区窄，解读 task2/3 结果时对 |α|=0.1 的波动要更敏感。
2. **NAT 训练（task2）对 VGG 必须正负 α 都覆盖**：与 SimpleCNN"压缩方向为主"不同，VGG 双向对称受创——这一差异本身是 task2 分析的看点（NAT 收益是否随模型脆弱模式而变化）。
3. **task3 分层 α（Exp2）的施压目标 = block4/block5**；fc 已确认为最敏感层，若分层接口支持读出层则优先纳入（视 task3 实现而定）。损伤由方向破坏承载，预期"仅校准"（Exp1，作用在幅值/分布层面）收益有限，与 SimpleCNN 处的预判一致，待数据验证。
4. **跨模型"最敏感层"规律闭环**：SimpleCNN → fc，VGG-11 → fc。ext1 三方对比口径已统一，resnet18 待验证其 fc 是否同样最敏感——若成立，"扰动损伤终点在分类头"可升格为论文级规律。
5. **过拟合备注**：VGG-100 的 33pp train/test gap 记入 limitations；按协议一致性原则不改训练配置。
6. **复现信息**：seed 42；协议同 §1；产物：`alpha_sensitivity.csv`、`layer_distribution_shift.csv`（含 fc，修复后重生成）、`accuracy_vs_alpha.png`、`error_accumulation.png`（含 fc 终点）、`histogram_block2.png`、`histogram_block5.png`。
