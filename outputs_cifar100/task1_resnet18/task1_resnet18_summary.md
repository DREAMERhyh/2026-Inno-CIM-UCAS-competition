# Task1 总结 — ResNet-18 @ CIFAR-100：非线性失真 α 敏感性分析

## 1. 实验设置

| 项目       | 内容                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------- |
| 模型       | ResNet-18（4 个 stage + fc，BasicBlock，输出 100 类）                                       |
| 干净权重   | `checkpoints_cifar100/resnet18/best_model.pth`，best_test_acc = **72.09%**（epoch 149/200） |
| 评估数据   | CIFAR-100 测试集 10,000 张（全量）                                                          |
| α 网格     | {−0.3, −0.2, −0.1, 0.0, +0.1, +0.2, +0.3}，全部观测层同时注入                               |
| 层分析协议 | 固定 500 张样本，观测 layer1/layer2/layer3/layer4/fc 共 5 层输出；指标：RME、余弦相似度     |
| 产物目录   | `outputs_cifar100/task1_resnet18/`                                                          |

**一致性核对**：α=0 精度 72.09 与 best_test_acc 精确一致 ✓；α=0 loss 1.3996 vs final_test_loss 1.3865（差 0.9%）——源于 best（epoch 149）与 final（epoch 200）检查点不同（final_test_acc 71.95 ≠ 72.09 佐证），非数据问题。

**训练动态备注**：final_train_acc 99.98% vs final_test_acc 71.95%（gap 28.0pp，train loss 0.0033）——重度过拟合，程度介于 SimpleCNN（13.8pp）与 VGG-11（33.1pp）之间。

## 2. 整网精度扫描

| α    | CIFAR-100 Acc | Δ(pp)  | 相对跌幅 | CIFAR-10 Acc | Δ(pp)  | 相对跌幅 |
| ---- | ------------- | ------ | -------- | ------------ | ------ | -------- |
| −0.3 | 3.25          | −68.84 | 95.5%    | 12.38        | −79.71 | 86.6%    |
| −0.2 | 9.25          | −62.84 | 87.2%    | 32.98        | −59.11 | 64.2%    |
| −0.1 | 45.74         | −26.35 | 36.6%    | 81.64        | −10.45 | 11.3%    |
| 0.0  | **72.09**     | 0      | 0        | 92.09        | 0      | 0        |
| +0.1 | 51.80         | −20.29 | 28.1%    | 82.78        | −9.31  | 10.1%    |
| +0.2 | 10.51         | −61.58 | 85.4%    | 43.97        | −48.12 | 52.3%    |
| +0.3 | 2.70          | −69.39 | 96.3%    | 17.08        | −75.01 | 81.5%    |

**关键发现**：

1. **α=0 即峰值**（3/3 模型一致），但**安全平坦区完全消失**：|α|=0.1 已损失 28~37% 相对精度（SimpleCNN 同强度仅 3~5%、VGG 约 10%）。三段式"平坦→肩部→崩塌"被压缩成近乎垂直的悬崖，肩部推到 |α|≈0.05 以下。
2. **|α|=0.3 双向坍缩至近随机水平**：+0.3 仅剩 2.70%、−0.3 剩 3.25%（随机水平 1%），相对损失 95~96%——三个模型中唯一在两个方向上都打穿到接近随机的。
3. **符号近乎对称、且不对称方向与前两个模型相反**：|α|=0.3 时正/负跌幅比 1.01（SimpleCNN 1.87、VGG 1.18）；而 |α|=0.1/0.2 与 CIFAR-10 全部强度上均呈**轻微负向（放大）更伤**（如 |α|=0.1 比 1.30、CIFAR-10 |α|=0.3 比 0.94）。即 SimpleCNN/VGG 怕压缩，ResNet-18 略怕放大——"更脆弱的方向"是架构相关的。
4. **loss 爆炸最剧烈且方向倒挂**：−0.3 时 loss 26.63 = clean 的 19.0 倍（SimpleCNN 2.25×、VGG 6.2×）；−0.3 的 loss（26.6）远高于 +0.3（8.3）而精度相近——放大幅值产生更大 logits → 更自信的错误预测；压缩则产生低置信输出。与 fc RME 的方向不对称（10.50 vs 3.14）同源。

## 3. 逐层分布偏移分析

各层平均余弦相似度（跨 α≠0）：layer1 0.942 > layer2 0.851 > layer3 0.703 > layer4 0.579 > **fc 0.403**。

最强扰动 |α|=0.3 时各层指标（RME / cos）：

| 层     | α=+0.3             | α=−0.3          |
| ------ | ------------------ | --------------- |
| layer1 | 0.405 / 0.8923     | 0.568 / 0.8925  |
| layer2 | 0.685 / 0.7038     | 1.166 / 0.7564  |
| layer3 | 0.845 / 0.5162     | 2.354 / 0.5136  |
| layer4 | 1.015 / 0.4324     | 2.233 / 0.3860  |
| fc     | 3.143 / **0.1476** | 10.495 / 0.1184 |

**关键发现**：

1. **fc 最敏感（3/3 确认，升格为跨模型规律）**：平均 cos 0.403，误差沿深度单调累积，layer4→fc 为最陡一跳（+0.3 时 0.432→0.148，接近腰斩）。SimpleCNN、VGG-11、ResNet-18 三种架构的损伤终点一致指向分类头。
2. **"方向破坏载体"机制第三次确认，且为本系列最干净的一次**：fc cos 与精度的秩相关 ρ≈0.94，六测点中唯一倒挂发生在 −0.3/+0.3 两个已崩塌点之间（3.25% vs 2.70%，均近随机、差异在评估噪声量级）——即在每个仍保留功能的强度点上，fc 方向保持度严格预测精度排序。三模型 3/3 成立，可作为论文核心机制论点。
3. **RME 脱钩极端化**：−0.3 的 fc RME = 10.50，为三个模型全部数据中的最大值，而其精度反而好于 +0.3（RME 仅 3.14）。至此可定论：**fc 的 RME 无跨层/跨方向可比性，跨层比较以 cos 为唯一主指标**（SimpleCNN 提出的口径建议，3/3 证据封板）。
4. **浅层即受可见影响，逐层放大**：layer1 在 ±0.3 的 cos 已降到 0.892（SimpleCNN conv1 0.993、VGG block2 0.943）——ResNet 的失真累积从更差的浅层基线起步。直方图：layer1（+0.3）零点峰 3.15→2.93、0.5 附近中段隆起（0.45→0.55），轻度展布；layer4 零点峰 3.17→3.99（+26%）、尾部收缩，强烈向零坍缩。"压缩向零、随深度放大" 3/3 确认，且 ResNet 的放大曲线整体前移。
5. **同 α 下失真累积速率约为 VGG 的两倍**：|α|=0.1 时 fc cos（0.719/0.776）已相当于 VGG fc 在 |α|≈0.15~0.2 的水平（VGG fc：0.1 时 0.892/0.903 → 0.2 时 0.643/0.683）。

## 4. 与 CIFAR-10 对比（同模型、同协议）

1. **定性结论全部迁移**：α=0 峰值、深度单调累积、cos 主导精度损失、fc 终点——3/3 数据集×模型组合复现。
2. **CIFAR-100 相对脆弱性全面更高**：每个匹配强度点的相对跌幅都更大（+0.2：85.4% vs 52.3%；−0.1：36.6% vs 11.3%）；且 CIFAR-100 坍缩至近随机（2.7~3.3%），CIFAR-10 尚保留 12~17%。
3. **绝对跌幅量级依旧与类别数基本无关**：+0.3 时 −69.4 vs −75.0pp（CIFAR-10 反而更大），三个模型全部符合此规律。
4. **跨模型总表（ext1 核心素材）**：

   | 指标                        | SimpleCNN | VGG-11 | ResNet-18 |
   | --------------------------- | --------- | ------ | --------- |
   | clean acc @100 (%)          | 59.99     | 67.09  | 72.09     |
   | +0.3 相对跌幅 @100          | 53.2%     | 74.8%  | **96.3%** |
   | −0.3 相对跌幅 @100          | 28.5%     | 63.5%  | **95.5%** |
   | \|α\|=0.1 最大相对跌幅 @100 | 4.6%      | 10.4%  | **36.6%** |
   | +0.3 相对跌幅 @10           | 35.1%     | 59.1%  | 81.5%     |

   **clean 精度与扰动鲁棒性完全反相关**（两个数据集、两个方向、全部强度上排序一致：SimpleCNN 最稳 > VGG > ResNet-18 最脆，而 clean 精度排序恰好相反）。候选解释（假设，待 ext1/ext2 检验）：有效深度递增（4 vs 8 vs 17 个卷积层）+ 恒等跳连无衰减地前传失真；注入位点数在协议中三模型相等（5 个），差异来自内部深度与残差拓扑。

## 5. 结论与对后续任务的启示

1. **协议不变**，沿用 {0.1, 0.2, 0.3} 保证跨模型可比；但解读 ResNet 结果时注意其动态范围被压缩——|α|=0.1 已在悬崖段，0.3 已近随机天花板。
2. **task2（NAT）在 ResNet-18 上恢复空间最大**（三模型中跌幅最深）；关注 NAT 收益是否集中在中小强度（大强度受近随机天花板限制），以及"放大更伤"的符号特性是否改变 NAT 的最优噪声配置。
3. **task3 分层 α 施压目标 = layer3/layer4/fc**；残差通路作为失真传播候选载体记入解释框架；"仅校准（Exp1）收益有限"的预判沿用。
4. **两条规律升格为论文级结论**：① 扰动损伤终点在分类头（3/3 架构）；② 表征方向破坏（cos）是精度损失的载体，幅值偏移（RME）脱钩（3/3）。外加一条新论点：**clean 精度与失真鲁棒性反相关（n=3，双数据集一致）**——注意 n=3 且深度/架构混淆，表述需留有余地。
5. **过拟合备注**：gap 28.0pp 记入 limitations；按协议一致性原则不改训练配置。
