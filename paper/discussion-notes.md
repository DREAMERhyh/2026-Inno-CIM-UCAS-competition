## 一、Opening（2-hop）：R2 + R3 + R4 + R5 + R6 合起来意味着什么

**向上抽象到 2-hop**：

> 在这类失真下，"修复"的正确对象不是**参数**，而是**解码**。

三条证据线交汇到这一点：

1. **R2** 直接测量到信息仍在线性可达范围内（headroom +20.12 pp）；
2. **R4** 用四条独立路径证明参数空间的训练无法取用这份信息——包括"把训练分布扩到 ±0.5"，模型在 α=+0.5 上仍只有 2.71%；
3. **R3** 换一个读出（主干一个字都不动）就拿回了 13~23 个百分点。

这三条单独看都可以被别的解释吸收：探针可能过强、"训练不够久"、读出适配可能是"再分配"而非净增益。**并置之后，"再分配"这个解释被排除**——单点读出适配（只对 α=+0.3 拟合）确实是再分配（该点 +24.70，clean −20.36，mean7 反而低于基线），但**分布式的读出适配**（在 α ~ U[±0.3] 上训练）在每个扫描点都不显著劣化、且尾部与中带同时提升。同一个读出层的两种训练方式给出质上不同的结果，说明起作用的不是"读出被放开了"这件事本身。

**为什么这与常规鲁棒性直觉相反**：

常规对抗鲁棒性的直觉是"扰动在参数空间里被吸收"——对抗训练之所以有效，是因为训练分布覆盖了测试分布。但本研究里的扰动是**确定性的、输入相关的系统误差**：同一个输入永远产生同一个失真，且它逐层累积、与信号幅度挂钩。这类误差不摧毁信息，它改变信息的**几何**——把深层表征的有效秩从 38.78 压到 30.78（+0.3）乃至 19.04（+0.5），同时 Fisher 判据反而升高。也就是说：类间距没变小，**维度**丢了。在一个丢维度的子空间里，"把参数训得更适应"不会增加维度；换一个读出却可以在剩余的维度里重新找到判别方向。

**R5 把这层解释接上定量**：可恢复量随秩损失单调下降（20.6/33.3/58.7% ↔ 72.2/70.2/36.9%，r = −0.960）。**R6 补上另一半**：降维恰恰是保住秩的手段——5×MaxPool 把深层空间元素数从 256 压到 16，在同一 α 下保住了更多有效维度。两条看起来毫无关系的杠杆（换读出、加池化）在这里被同一个量联系起来。

## 二、Middle（general principle）：更一般地可能是什么

> **当失真具有"确定性、逐层累积、且权重因硬件原因不可重训"三个性质时，鲁棒性的杠杆位置由
> 信息在哪一层被破坏决定，而不是由"哪一层参数多"或"哪一层最脆弱"决定。**

这条原理的可迁移形式是一个**测量顺序**，而不是一个方法：

1. **先测 headroom**（在冻结主干的末端特征上重训一个线性探针，与自带头比较）。
   headroom 小 → 信息真的没了，只能动表征，回到常规鲁棒训练；
   headroom 大 → 信息还在，杠杆在读出，训练端的投入大概率是浪费。
2. **若杠杆在读出，再测表征的秩损失**，它给可恢复量一个上界提示（本研究：秩损失 20~59% 对应恢复率 72~37%）。
3. **再看架构端有没有零成本的降维空间**（本研究：池化密度）。

本研究给出 headroom 的两个**对照下界**：同一套探针在**加性高斯噪声**这条对照通路上只有 **+7.00**，而非线性失真是 **+20.12**（`outputs_cifar100/v3_probe_info_death/probe_results.csv`）。也就是说"先测 headroom"这个动作本身有区分力——它会把随机扰动和确定性系统误差分开，前者需要的是表征层面的平滑，后者需要的是解码层面的重定向。

## 四、Limitation（每条必须导致一个由 findings 引出的重要问题 unresolved）

**L1. 失真模型是参数化假设，且没有硬件实测。**
全研究的收益都测在 $y=\alpha\hat x^3+(1-\alpha)\hat x$ 这一族上，逐层、逐样本 ∞-范数归一化。
→ **导致的问题**：本研究的 central claim 依赖"失真是确定性且与幅度相关"这个性质；若真实 CIM 的非线性更接近高阶多项式、带温度漂移、或器件间失配有随机成分，headroom 还有多大、读出杠杆还成不成立，**本研究无法回答**。
（已知的下界来自加性高斯这条对照通路：headroom 从 +20.12 掉到 +7.00。）

**L2. 深层主干是单次训练产物。**
VGG-11 与 ResNet-18 的主干权重各只训了一次；读出侧的 3 seed 只反映读出训练的数据顺序与 α 采样随机性，**不含主干训练方差**。而深层上已知的方差已经不小：固定主干上换读出种子，clean 从 63.54 摆到 67.61（±1.85），尾部摆到 ±3.40。
→ **导致的问题**：R5 与 R8 里所有涉及深层主干的差值（含 ResNet-18 的门控红利 −1.14）**是否在主干种子方差内，本研究无法裁决**。

**L3. 池化保护的定量分解没有定下来。**
同协议 3 seed 下 5×avg 与 5×max 的 drop 差 **+1.17**，落在预登记的 1~2 pp 区间；差值的标准误 ≈1.03（z≈1.1）。
→ **导致的问题**：R6 只能给出方向性结论（保护主要来自降维），**"降维 : 非均值聚合"的定量比例本研究无法裁决**。而且这条路的根本瓶颈是 avg 与 max 的差距本身太小——继续加种子是低效的。

**L4. 秩-恢复关系只有三个点。**
→ **导致的问题**：r = −0.960 说明方向一致，但曲线是线性、有阈值、还是"先平后塌"的折线，**三点无法回答**。这直接影响能不能把可恢复量写成一个由秩损失预测的上界。

**L5. 跨实现的 5.55 pp 差异未归因。**
`task2_nat.py` 与 `v3_methods_simplecnn.py` 训出的 NAT 权重稳定差 5.55 pp（21.03±1.00 vs 26.58±0.29，z=9.4）。已排除：种子噪声、α 采样粒度、RNG 消耗数、评估路径（8/8 逐位相同）、训练动力学（逐 epoch loss 差 ≤0.016）。
→ **导致的问题**：同 seed 的逐 epoch loss 全程贴合（差 ≤0.016）而尾部差 5.55，这个**量级不一致**本研究无法解释。它的实际后果是硬的：**任何精度数字不可跨训练实现移植**，部署校准必须与部署训练同实现、同路径。

**L6. 读出适配要求读出层可写。**
readout-NAT 的前提是最后那个线性层能重训；门控还额外要求同时拿到两个头的 logits。
→ **导致的问题**：若某款 CIM 把读出层也固化在阵列里，本研究的方法**整体不成立**。本研究只给出了结构条件（读出层在数字域或可重写，占全模型参数 5.04% / 0.55%），**没有评估过面积、延迟、功耗的真实代价**——这需要 RTL/功耗仿真或流片实测，超出本研究范围。

## 五、Future Study（从 Limitation 推导，不另起炉灶）

| 来自 | 下一步 | 成本估计 |
|---|---|---|
| L1 | 结合真实 CIM 宏（SRAM/Flash/ReRAM）的实测特性标定失真参数，在更高阶多项式 + 温度依赖 + 器件失配的形态族上重测 headroom 与读出杠杆 | 需硬件 |
| L2 | 每个深层主干重训 2 个 seed（VGG-11 / ResNet-18），重算 R5、R8 全部深层差值的置信区间 | ≈16 h |
| L3 | 换效应量更大的对照：池化窗口 2×2 vs 4×4，或池化层的位置分布；或补到 ≥8 seeds/组 | ≈10 h |
| L4 | 补第 4 个容量档的秩-恢复点，判定曲线形状 | 1 次训练 + 探针 |
| L5 | 逐行对齐两个训练循环做二分（换评估路径已验证无效，**必须动训练循环**） | ≥2 次训练 |
| L6 | 把读出层映射到真实数字后端，做面积/延迟/功耗的推演或仿真 | 需 RTL |

**已明确排除、不再列为方向**（来自项目内部的负结果，避免后来者重走）：
读出训练时混入干净样本（`clean_ratio` 0.3/0.5）回收 clean 代价——权衡中性，两档之间非单调；
"在 ADC 前注入随机噪声"复现 Dithering——H1 已否决，等剂量注噪零增益；
"门控两头都不崩"做成量化自检——两种定义在 n=7 上都不分离。
