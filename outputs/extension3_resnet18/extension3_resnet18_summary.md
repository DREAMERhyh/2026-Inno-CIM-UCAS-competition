# 拓展研究3：量化误差与非线性误差联合影响 —— ResNet-18 实验总结

## 1. 实验概述
本实验在 ResNet-18（11.17M 参数，干净精度 92.09%）上复现拓展研究3 的联合误差分析。在推理时同时注入**非线性失真**（模拟域 MAC 固有）和**量化误差**（ADC 模数转换精度损失），系统分析单独量化影响及联合影响的叠加特性，并与 SimpleCNN 进行跨架构对比。

- **模型**：ResNet-18（18 层残差网络，92.09% 干净精度）
- **量化比特数**：8、6、4、3、2 bit（逐样本动态缩放 QDQ）
- **非线性强度**：α ∈ [-0.3, 0.3]
- **联合注入顺序**：先非线性失真（模拟 MAC），再量化（ADC），共 35 种组合

## 2. 单独量化误差影响

|     Bit      | ResNet-18  | SimpleCNN（对比） | 分析                                      |
| :----------: | :--------: | :---------------: | ----------------------------------------- |
| 32（无量化） |   92.08%   |      84.81%       | 干净基线                                  |
|      8       |   92.08%   |      84.81%       | **8bit 完全无损**，两模型均保持基线精度   |
|      6       |   91.81%   |      84.58%       | 6bit 仅损失 0.27%，量化噪声可忽略         |
|    **4**     | **88.48%** |    **74.71%**     | 4bit 仅损失 3.60%，SimpleCNN 损失 10.10%  |
|      3       |   59.94%   |      28.99%       | 3bit 精度腰斩但保持 60%，SimpleCNN 仅 29% |
|      2       |   10.54%   |      11.08%       | 2bit 完全失效，两者均接近随机             |

**关键发现一：ResNet-18 对量化的鲁棒性远超 SimpleCNN，量化悬崖阈值推迟到 3bit。**

在 4bit 量化下，ResNet-18 仅损失 3.60%（92.08% → 88.48%），而 SimpleCNN 损失了 10.10%（84.81% → 74.71%）。在 3bit 下，ResNet-18 仍保持 59.94% 的精度（SimpleCNN 仅 28.99%）。残差连接的"信息双路径"特性——恒等映射路径始终传递原始信号——使得部分被量化截断的信息可以通过 shortcut 得以保留，从而推迟了量化悬崖的出现。

**物理直觉**：在 ResNet 的每个 BasicBlock 中，输出 = F(x_q) + x。即使 F(x_q) 因 4bit 量化产生了少量误差，shortcut 路径的 x 仍保留了 8bit 精度的原始信息。两者相加后，量化误差被"稀释"了约一半。而在 SimpleCNN 中，输出 = F(x_q)，量化误差无处可逃，逐层累积。

## 3. 联合误差影响（α=+0.3, bit=4）

| 指标                      |        ResNet-18        |    SimpleCNN（对比）     |
| ------------------------- | :---------------------: | :----------------------: |
| 仅非线性（α=+0.3, 32bit） |         16.99%          |          54.92%          |
| 仅量化（α=0, 4bit）       |         88.48%          |          74.71%          |
| 单独跌幅（非线性+量化）   | 75.09% + 3.60% = 78.69% | 29.89% + 10.10% = 39.99% |
| 联合实际精度              |       **17.38%**        |        **41.24%**        |
| 联合跌幅                  |         74.70%          |          43.57%          |
| **超加性判断**            |     **亚线性抵消**      |        超加性恶化        |

**关键发现二：ResNet-18 出现了亚线性抵消效应，与 SimpleCNN 的超加性恶化截然相反。**

SimpleCNN 上联合跌幅（43.57%）大于单独跌幅之和（39.99%），两种误差相互"共振"产生了额外的 3.58% 损失。但 ResNet-18 上联合跌幅（74.70%）反而**小于**单独跌幅之和（78.69%），两种误差并未叠加恶化，而是出现了"饱和抵消"——非线性失真已经将精度从 92% 打到 17%，此时再叠加量化误差几乎没有进一步恶化的空间。

**物理本质**：非线性失真已将 ResNet-18 的深层特征彻底摧毁（α=+0.3 时 fc 余弦相似度仅 0.127，几乎与干净特征正交）。此时模型对任何额外扰动都"无感"——信号已被摧毁，再加噪声也不会变得更差。这是一种"地板效应"（floor effect）式的抵消，而非真正的鲁棒性。

### 4.2 α=+0.3（强非线性）时各 bit 下的联合精度

|  Bit  | 联合精度 | 说明                         |
| :---: | :------: | ---------------------------- |
|   8   |  16.99%  | 非线性已主导，bit 数无关紧要 |
|   6   |  17.14%  | 同上                         |
|   4   |  17.38%  | 同上                         |
|   3   |  17.28%  | 同上                         |
|   2   |  9.73%   | 2bit 进一步恶化，但幅度有限  |

**关键发现三：当非线性失真将精度打到 17% 附近时，量化比特数（4bit 及以上）几乎无影响。**

α=+0.3 时，8bit 到 3bit 的精度全部在 17.0-17.4% 之间，量化精度的差异被非线性失真的"饱和破坏"完全淹没。直到 2bit（精度 9.73%）才出现额外的显著下降——因为 2bit 量化本身已使模型无法工作（α=0 时仅 10.54%）。

### 4.3 轻失真下的联合效应

|   α   | bit=4 时精度 | 仅非线性精度 |       量化额外损失       |
| :---: | :----------: | :----------: | :----------------------: |
| -0.1  |    75.18%    |    81.64%    |          -6.46%          |
|  0.0  |    88.48%    |    92.08%    |          -3.60%          |
| +0.1  |    75.69%    |    82.78%    |          -7.09%          |
| +0.2  |    39.23%    |    43.97%    |          -4.74%          |
| +0.3  |    17.38%    |    16.99%    | +0.39%（量化反而略高！） |

在轻失真区间（α=±0.1），量化额外造成约 6-7% 的损失——这是"正常"的叠加。但在极强失真下（α=+0.3），4bit 量化精度（17.38%）甚至略高于 32bit 纯非线性精度（16.99%）。这不是量化"改善了"精度，而是量化噪声的随机抖动偶然打破了非线性失真的某些确定性破坏模式（类似于 dithering 效应）。

## 5. 与 SimpleCNN 的系统性对比

| 维度                   |     SimpleCNN     |      ResNet-18       |
| ---------------------- | :---------------: | :------------------: |
| 干净精度               |      84.81%       |        92.08%        |
| 量化悬崖阈值           |  4bit（-10.10%）  |   3bit（-32.14%）    |
| 4bit 量化单独损失      |      -10.10%      |      **-3.60%**      |
| 3bit 量化单独损失      |      -55.82%      |       -32.14%        |
| 非线性脆弱性（α=+0.3） | 55.08%（-29.89%） |  17.08%（-75.01%）   |
| 联合效应类型           |    超加性恶化     |      亚线性抵消      |
| 核心瓶颈               |   两种误差耦合    | **非线性单独已致命** |

**关键发现四：残差连接是量化容错的天使，却是非线性放大的魔鬼。**

ResNet-18 的残差连接对量化噪声提供了出色的容错——4bit 仅损失 3.6%，远优于 SimpleCNN 的 10.10%。但同时残差连接也放大了非线性失真——α=+0.3 时损失 75.01%，远劣于 SimpleCNN 的 29.89%。两种效应在 ResNet-18 身上形成了极端的"分裂人格"。

## 6. 对赛题的启示

1. **联合优化的优先级取决于模型架构**：对于 ResNet-18，非线性补偿的优先级远高于量化补偿。将 ADC 从 4bit 提高到 8bit 在 α=+0.3 时几乎没有收益（17.38% vs 16.99%），但将 MAC 的 α 从 0.3 降低到 0.2 就能将精度从 17% 恢复到 39%。资源投入做 MAC 线性化校准，比对 ADC 提高 1-2bit 精度有效得多。

2. **"亚线性抵消"不是好消息**：ResNet-18 的联合跌幅小于单独跌幅之和，看似"好"，但这是因为非线性失真已将模型推至性能底线。对于实际部署，需要确保两种误差的联合效应在可接受范围内，而非寄希望于"地板效应"来掩盖问题。

3. **量化悬崖的架构依赖性**：SimpleCNN 的量化悬崖在 4bit，ResNet-18 的量化悬崖在 3bit。如果存算一体芯片的 ADC 精度受限于 4bit，ResNet-18 几乎不受影响（-3.60%），而 SimpleCNN 会损失 10%——架构选择直接决定了 ADC 精度的最低要求。

4. **VGG-11 可能是更优的折中方案**：任务1 已证明 VGG-11 的非线性脆弱性介于 SimpleCNN 和 ResNet-18 之间（α=+0.3 时 36.70%），而拓展3 待测的量化容错能力可能同样介于两者之间。VGG-11 没有残差连接的"非线性放大"效应，同时深层结构可能提供一定的量化容错——这需要实际数据来验证。
