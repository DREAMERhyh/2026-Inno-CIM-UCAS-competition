# 拓展研究2：高斯噪声与非线性失真对比 —— 实验总结

## 1. 实验概述
本拓展研究系统对比了**高斯加性噪声**（x + N(0, σ²)）与**三次多项式非线性失真**（y = αx³ + (1-α)x）对模型推理精度及内部表征的不同影响机制。在干净模型（SimpleCNN, 84.90%）和任务3最优鲁棒模型（Exp2, 87.37%）上分别进行两种扰动的整网精度扫描和层输出分布偏移分析，回答三个核心问题：两种扰动的精度衰减模式是否相同？误差在层间的累积路径有何差异？针对非线性失真训练的鲁棒性能否迁移到高斯噪声？

- **扰动参数**：非线性 α ∈ [-0.3, 0.3]，高斯 σ ∈ [0.05, 0.30]
- **评估模型**：SimpleCNN（干净） + Exp2（校准+分层加权，任务3最优）
- **分析维度**：整网精度扫描 + 层输出 RME/余弦相似度 + 误差累积曲线 + 鲁棒性迁移

## 2. 整网精度对比

### 2.1 干净模型（SimpleCNN）

| 扰动强度 | 非线性失真 (α) |  精度  | 高斯噪声 (σ) |  精度  |
| :------: | :------------: | :----: | :----------: | :----: |
|    弱    |     α=-0.1     | 83.26% |    σ=0.05    | 83.06% |
|    中    |     α=+0.1     | 82.66% |    σ=0.10    | 76.21% |
|    强    |     α=+0.2     | 73.50% |    σ=0.15    | 66.07% |
|   极强   |     α=+0.3     | 55.08% |    σ=0.30    | 37.02% |

### 2.2 鲁棒模型（Exp2）

| 扰动强度 | 非线性失真 (α) |  精度  | 高斯噪声 (σ) |  精度  |
| :------: | :------------: | :----: | :----------: | :----: |
|    弱    |     α=-0.1     | 85.89% |    σ=0.05    | 83.22% |
|    中    |     α=+0.1     | 86.54% |    σ=0.10    | 69.39% |
|    强    |     α=+0.2     | 81.44% |    σ=0.15    | 50.71% |
|   极强   |     α=+0.3     | 68.76% |    σ=0.30    | 20.42% |

### 关键发现一：高斯噪声的破坏力远超非线性失真

在"可比强度"下（α=0.2 精度约 73%，σ=0.15 精度约 66%），高斯噪声已造成更大的精度损失。当参数增大到极强（α=0.3 vs σ=0.3），高斯噪声将 Exp2 精度打到仅 20.42%，模型几乎完全失效——而非线性失真下仍有 68.76%。这是因为高斯噪声是**无差别全局加性扰动**，每一层、每个神经元同时受到随机干扰，而离散性失真仅对信号幅度敏感、浅层影响较小。

## 3. 层误差累积路径对比

### 3.1 最强扰动下的各层余弦相似度（SimpleCNN）

| 层           | 非线性 α=+0.3 | 高斯 σ=0.3 |          差异          |
| ------------ | :-----------: | :--------: | :--------------------: |
| conv1_output |    0.9928     | **0.9102** |   浅层即出现巨大差异   |
| conv2_output |    0.9937     |   0.9034   |   高斯噪声已显著偏移   |
| conv3_output |    0.9476     |   0.7890   |      差距持续扩大      |
| conv4_output |    0.9010     |   0.5428   | 高斯噪声下特征近乎崩溃 |
| fc_output    |    0.6786     |   0.5414   |  两种扰动在决策层趋近  |

### 3.2 最强扰动下的各层余弦相似度（Exp2）

| 层           | 非线性 α=+0.3 | 高斯 σ=0.3 |             差异             |
| ------------ | :-----------: | :--------: | :--------------------------: |
| conv1_output |    0.9931     |   0.9168   |          浅层差异大          |
| conv2_output |    0.9927     |   0.8791   |                              |
| conv3_output |    0.9522     |   0.7790   |                              |
| conv4_output |    0.8956     |   0.4481   |      高斯下特征彻底瓦解      |
| fc_output    |  **0.8307**   | **0.3463** | 非线性下鲁棒，高斯下完全崩溃 |

### 关键发现二：两种扰动的层累积模式截然相反

- **非线性失真**：误差从 conv3 开始**渐进累积**，fc 层虽最敏感但仍保持 0.67-0.83 的余弦相似度——网络深层仍保留了一定的语义信息。
- **高斯噪声**：误差呈现**"浅层即入侵、深层崩塌"** 的模式。conv1 的余弦相似度已降至 0.91，conv4 仅 0.45-0.54，fc 层 0.35-0.54。高斯噪声从前几层就彻底破坏了特征表达，导致后续所有层都在处理已被噪声污染的信号。

**物理本质差异**：
- 非线性失真是**确定性、输入幅度相关**的映射——小信号几乎不变，仅大信号被扭曲。浅层特征图的激活值通常较小（网络已学到稀疏表达），因此 conv1/conv2 受影响轻微。
- 高斯噪声是**随机性、输入无关**的加性扰动——无论信号大小，每个元素都被施加独立随机噪声。浅层的边缘/纹理等低级特征直接被噪声淹没，后续层无法恢复。

## 4. 鲁棒性迁移分析

### 4.1 Exp2 在高斯噪声下的表现 vs SimpleCNN

|   σ   | SimpleCNN |  Exp2  |   Uplift    |
| :---: | :-------: | :----: | :---------: |
| 0.05  |  83.06%   | 83.22% |   +0.16%    |
| 0.10  |  76.21%   | 69.39% | **-6.82%**  |
| 0.15  |  66.07%   | 50.71% | **-15.36%** |
| 0.20  |  55.93%   | 36.45% | **-19.48%** |
| 0.25  |  46.35%   | 27.50% | **-18.85%** |
| 0.30  |  37.02%   | 20.42% | **-16.60%** |

### 关键发现三：针对非线性失真的鲁棒性**不能迁移**到高斯噪声，甚至出现**负迁移**

Exp2 在高斯噪声下的表现**全面劣于**SimpleCNN，且差距随 σ 增大而急剧扩大。σ=0.15 时 Exp2 落后 15.36 个百分点，σ=0.30 时落后 16.60 个百分点。

**原因分析**：
- Exp2 的分层加权训练让 fc 层专门适应了 ±0.3 的非线性失真模式，这种适应性是**对特定失真函数的过拟合**——校准模块学到的是"αx³+(1-α)x"的逆映射，而非通用的去噪能力。
- Exp2 的参数量（259,050）略大于 SimpleCNN（242,474），额外的 16K 参数在校准模块中。当面对完全不同的扰动类型时，这些参数不仅无法帮助，反而可能放大噪声——校准模块的 MLP 对输入噪声同样敏感，残差连接将噪声直接传入分类头。
- 这一发现具有重要的工程启示：**针对特定失真训练的鲁棒模型不具备跨扰动泛化能力**。真实部署时若无法预知芯片失真的精确模型，应使用更通用的鲁棒训练策略（如数据增强、Dropout、权重噪声等），而非依赖于精确的失真建模。

## 5. 对赛题的启示

- **任务1-3 的合理性得到验证**：赛题明确给出了非线性失真模型 y=αx³+(1-α)x，且实验证明这种失真可以通过针对性训练（NAT + 分层加权 + 校准模块）有效缓解（α=+0.3 精度从 55.08% 提升至 68.76%）。如果赛题没有给出精确模型，仅靠通用鲁棒方法效果会大打折扣。
- **真实芯片部署的提醒**：若实际芯片的非线性特性与赛题给定的三次多项式存在偏差，Exp2 模型可能表现不佳。建议在最终报告中讨论"模型失配对鲁棒性的影响"作为 future work。
- **高斯噪声可作为对比基线写入报告**：说明"随机噪声"和"输入相关失真"是两种本质不同的扰动，赛题的存算一体场景更接近后者。
