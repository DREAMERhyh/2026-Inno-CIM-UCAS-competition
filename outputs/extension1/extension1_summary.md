# 拓展研究1：网络结构与参数量对非线性误差的影响 —— 实验总结

## 1. 实验概述
本拓展研究对比 **SimpleCNN**（0.24M 参数，4层普通卷积）与 **ResNet-18**（11.17M 参数，18层残差网络）在不同非线性强度 α 下的精度衰减模式，探究网络结构与参数量对非线性误差敏感性的影响。

- **SimpleCNN**：干净精度 84.90%，参数量 242,474，4 次非线性注入（4 Conv + 1 Linear）
- **ResNet-18**：干净精度 92.09%，参数量 11,173,962，18 次非线性注入（17 Conv + 1 Linear）
- **α 扫描范围**：[-0.3, -0.2, -0.1, 0.0, 0.1, 0.2, 0.3]

## 2. 核心发现：大模型反而更脆弱

### 2.1 干净精度 vs 失真鲁棒性

| 模型      | 参数量 |  干净精度  | α=+0.3 精度 |    跌幅     |
| --------- | :----: | :--------: | :---------: | :---------: |
| SimpleCNN | 0.24M  |   84.90%   |   55.08%    | **-29.82%** |
| ResNet-18 | 11.17M | **92.09%** |   17.08%    | **-75.01%** |

ResNet-18 在干净数据上比 SimpleCNN 高出 **7.19 个百分点**（92.09% vs 84.90%），但在 α=+0.3 时精度反而比 SimpleCNN 低 **38.00 个百分点**（17.08% vs 55.08%）。过参数化在理想条件下带来了显著的精度增益，但**完全不意味着更强的鲁棒性**——事实恰恰相反。

### 2.2 负向失真下的灾难性崩溃

|   α   | SimpleCNN | ResNet-18  |  差距  |
| :---: | :-------: | :--------: | :----: |
| -0.3  |  76.06%   | **12.38%** | 63.68% |
| -0.2  |  79.99%   | **32.98%** | 47.01% |
| -0.1  |  83.26%   | **81.64%** | 1.62%  |
|  0.0  |  84.90%   | **92.09%** | -7.19% |
| +0.1  |  82.66%   | **82.78%** | -0.12% |
| +0.2  |  73.50%   | **43.97%** | 29.53% |
| +0.3  |  55.08%   | **17.08%** | 38.00% |

ResNet-18 在 α=-0.3 时精度仅 12.38%，接近随机猜测水平（10%）。这一崩溃比正向失真（α=+0.3 时 17.08%）更为严重，与 SimpleCNN 上"正向破坏力是负向的 3.4 倍"的规律完全相反。

### 2.3 精度衰减的非对称性反转

SimpleCNN 上正向失真（α>0）破坏力是负向（α<0）的 3.4 倍。但 ResNet-18 上这种非对称性**消失甚至反转**：
- SimpleCNN：α=+0.3 跌幅 29.82%，α=-0.3 跌幅 8.84% → 正向破坏力 3.4×
- ResNet-18：α=+0.3 跌幅 75.01%，α=-0.3 跌幅 79.71% → **双向均灾难性崩溃**

## 3. 原因分析：残差连接是双刃剑

### 3.1 误差注入次数的数量级差异
SimpleCNN 只有 4 个 Conv2d + 1 个 Linear = **5 个注入点**。ResNet-18 有 1 个 conv1 + 16 个 BasicBlock 内 Conv（4 layer × 2 block × 2 conv）+ 1 个 fc = **18 个注入点**。非线性失真在每个 Conv 的输入端被注入，经过 18 次累积后，误差被放大了远超线性叠加的程度。

### 3.2 残差连接加速了误差的正反馈
SimpleCNN 是纯前馈结构，每层输出仅取决于上一层的输出。但 ResNet-18 的残差连接使得：
$$output = F(x) + x$$
其中 F(x) 是经过两个卷积（每个都注入了非线性失真）的输出。当 x 本身已被前一层污染时，F(x) 进一步叠加失真，残差加法将两重失真合并传入下一层。这种"失真叠加"在 8 个 BasicBlock 中逐级放大，形成类似正反馈的累积效应。

### 3.3 过参数化的收益被误差放大完全吞噬
ResNet-18 的 11.17M 参数在干净数据上确实提供了更强的表达能力（+7.19% 精度），但这些参数学习到的特征模式在失真下变得毫无意义——模型对干净数据的"过拟合"越强，对未见失真分布的泛化能力反而越弱。

## 4. 对赛题的启示

1. **参数量不是鲁棒性的保证**：在存算一体芯片的部署场景下，更大的模型不仅没有容错优势，反而因为更深的层级结构累积了更多非线性误差。这一发现对真实硬件部署有重要的指导意义——在模拟存算架构下，**浅层轻量模型可能是比大模型更安全的选择**。

2. **残差结构需要针对性改造**：如果必须使用 ResNet 等深层残差网络，应考虑在残差连接中插入校准模块（如任务3 的 FeatureCalibration）或每层使用独立的失真感知归一化，阻断误差的正反馈循环。

3. **架构搜索的启发**：拓展1 证明了"非线性鲁棒性"和"干净精度"是两个需要独立优化的目标。未来的工作中，可以探索专门针对存算一体场景的轻量鲁棒架构（如限制深度、限制残差连接数量、在每个残差块后强制校准）。
