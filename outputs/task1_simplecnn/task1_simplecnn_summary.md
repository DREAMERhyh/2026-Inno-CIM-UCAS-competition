# 任务1：非线性误差敏感性分析 —— 实验总结

## 1. 实验概述
本实验模拟存算一体芯片中模拟域乘累加（MAC）运算的输入相关非线性失真，将失真模型 \(y = \alpha \cdot x^3 + (1-\alpha) \cdot x\) 注入 SimpleCNN 的所有 Conv2d 和 Linear 算子输入端，系统评估不同非线性强度 α 对 CIFAR-10 分类推理精度的影响，并分析误差在网络各层的传播与累积特性。

**实验配置**：
- 模型：SimpleCNN（4层卷积 + 全局平均池化 + 全连接，参数量约 0.24M (242,474)）
- 干净基线准确率：84.90%（α=0.0）
- α 扫描范围：[-0.3, -0.2, -0.1, 0.0, 0.1, 0.2, 0.3]
- 注入位置：5 个算子（conv1/conv2/conv3/conv4/fc）的输入激活值

## 2. 整网精度敏感性分析

### 2.1 精度衰减数据

| α      | Accuracy (%) | Accuracy Drop (%) |
| ------ | ------------ | ----------------- |
| -0.300 | 76.06        | 8.84              |
| -0.200 | 79.99        | 4.91              |
| -0.100 | 83.26        | 1.64              |
| 0.000  | 84.90        | 0.00              |
| 0.100  | 82.66        | 2.24              |
| 0.200  | 73.50        | 11.40             |
| 0.300  | 55.08        | 29.82             |

### 2.2 关键发现
- **正向非线性（α > 0）比负向（α < 0）破坏力显著更强**：α=+0.3 时精度暴跌 29.82%，而 α=-0.3 仅下降 8.84%。
- **精度衰减呈现非对称性**：相同 |α| 下，正向失真导致的精度损失约为负向的 3.4 倍（|α|=0.3 时对比）。
- **原因分析**：正向 α 使大信号被进一步放大，破坏激活值分布的平衡，尤其影响深层特征表达；负向 α 压缩大信号，对分布影响相对温和。

## 3. 层输出分布偏移分析

### 3.1 各层平均余弦相似度（跨所有非零 α）

| 层名          | 平均余弦相似度 |
| ------------- | :------------: |
| conv1_output  |     0.9972     |
| conv2_output  |     0.9975     |
| conv3_output  |     0.9770     |
| conv4_output  |     0.9553     |
| **fc_output** |   **0.8954**   |

- **最敏感层**：fc_output（余弦相似度 0.8954）
- **最不敏感层**：conv2_output（余弦相似度 0.9975）

### 3.2 关键发现
- **误差随网络深度累积，在分类头（fc 层）爆发**：前两个卷积层几乎不受影响（余弦>0.99），第三层开始加速劣化，fc 层相似度降至 0.90 以下。
- **深层语义特征严重失真**：conv4 层余弦相似度仅 0.955，表明高层抽象特征已发生显著偏移，直接影响最终分类决策。
- **fc 层极端敏感**：其 RME 值高达 2.0 以上（|α|=0.3），分布中心大幅偏离，是精度崩塌的直接原因。

## 4. 非线性失真方向的不对称性

选取 |α|=0.3 时 fc_output 的余弦相似度对比：
- α = -0.3：余弦相似度 0.911
- α = +0.3：余弦相似度 0.679（远低于负向）

**物理解释**：
- α > 0 时：\(y = 0.3x^3 + 0.7x\)，正输入被放大、负输入被压缩，激活值的正向偏移使网络原本学习到的阈值响应失效，深层特征分布剧烈变形。
- α < 0 时：\(y = -0.3x^3 + 1.3x\)，正输入被压缩、负输入被放大，整体对称性破坏较小，网络仍能部分维持原有决策边界。

**启示**：优化算法应优先针对 α>0 场景设计鲁棒性增强策略，可重点关注约束激活值的分布范围或对 fc 层输入进行归一化校准。

## 5. 对后续任务的指导

- **任务2（非线性感知训练）**：
  - 训练时应覆盖正负 α，但需重点强化 α∈[0.1, 0.3] 区间的鲁棒性。
  - 可尝试**分层加权训练**：对深层（conv4/fc）施加更强的正则化或更高的 α 采样概率。
- **任务3（鲁棒性增强）**：
  - **核心保护对象**：fc 层及 conv4 层；可设计特征校准模块（如自适应归一化、特征缩放）。
  - 鉴于误差在 fc 层爆发，在 fc 输入前插入可学习的非线性补偿单元（如轻量 MLP）可能有效。
  - 考虑结合量化误差研究（拓展任务），因为非线性失真与量化误差在深层可能产生叠加恶化效应。
