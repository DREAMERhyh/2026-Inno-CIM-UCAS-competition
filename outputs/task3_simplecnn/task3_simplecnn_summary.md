# 任务3：鲁棒性增强方法设计 —— 实验总结

## 1. 实验概述
本实验在任务2 NAT-Scratch（非线性感知从头训练）的基础上，提出并验证三种互补的鲁棒性增强方法，通过消融实验量化每种方法的独立贡献，最终确定最优方案。

**三种方法**：
- **方案A（架构增强）**：在 fc 层前插入残差校准模块（Feature Calibration），MLP 128→64→128 + 残差连接，参数量 16,640
- **方案B（分层加权训练）**：浅层（conv1/conv2）使用轻失真 α∈[-0.15, 0.15]，中层（conv3/conv4）使用标准失真 α∈[-0.3, 0.3]，深层（fc）固定交替 ±0.3
- **方案C（非对称采样）**：70% 概率从 [0, 0.3] 采样正向 α，30% 从 [-0.3, 0) 采样负向 α

**消融实验设计**：

| 实验                     | 校准模块 | 分层加权 | 非对称采样 | 目的                 |
| ------------------------ | :------: | :------: | :--------: | -------------------- |
| NAT-Scratch（任务2基线） |    ✗     |    ✗     |     ✗      | 基线对比             |
| Exp1_CalibOnly           |    ✓     |    ✗     |     ✗      | 验证校准模块独立效果 |
| Exp2_Calib+Layerwise     |    ✓     |    ✓     |     ✗      | 验证分层加权叠加效果 |
| Exp3_FullRobust          |    ✓     |    ✓     |     ✓      | 完整方案             |

- 训练配置：SGD + momentum=0.9 + CosineAnnealingLR，120 epochs，α 扫描范围 [-0.3, 0.3]

## 3. 关键发现

### 发现一：分层加权（方案B）是贡献最大的单项改进
从 Exp1→Exp2，α=+0.3 时准确率从 63.63% 跃升至 68.76%，**提升 5.13 个百分点**。分层加权让浅层在轻失真下学习稳定特征，同时将 fc 层暴露于 ±0.3 的极限失真中专门训练，精准打击了任务1发现的最脆弱瓶颈层。这是整个赛题中单项改进幅度最大的技术手段。

### 发现二：残差校准模块（方案A）有正则化效果，但单独不足以应对强失真
Exp1 干净精度 87.19%，较基线提升 0.70%，但 α=+0.3 时精度反而略低于基线（63.63% vs 64.23%）。说明轻量 MLP 校准模块本身能提升泛化性，但面对强非线性失真时，仅靠 16K 参数的残差映射难以完全补偿 fc 层输入的分布偏移。它需要配合分层加权才能发挥协同作用。

### 发现三：非对称采样（方案C）边际贡献极小
Exp2→Exp3，α=+0.3 仅从 68.76% 提升至 69.14%（+0.38%）。70%/30% 的偏置采样并未带来实质性增益——120 epoch 的总训练量已经让模型在对称采样下充分见到了足够的正向失真样本。**方案C可舍弃，不影响最终效果。**

### 发现四：负向 α 下存在轻微的鲁棒性退化
Exp2 在 α=-0.3 时准确率 78.64%，低于 NAT-Scratch 的 81.54%（-2.90%）。这是因为分层加权给浅层分配了 α∈[-0.15, 0.15] 的轻失真范围，模型在训练时很少见到 |α|=0.3 的负向大失真输入。但由于正向失真破坏力是负向的 3.4 倍（任务1结论），这是一个合理的工程权衡。

### 发现五：最优方案 = Exp2（校准模块 + 分层加权）
Exp2 在所有正向 α 下均显著优于基线，干净精度 87.37%，α=+0.3 精度 68.76%，实现了干净精度与鲁棒性的双赢。

## 4. 全赛题进展总览

| 阶段      | 方法                      |  干净精度  | α=+0.3 精度 |    跌幅     |
| --------- | ------------------------- | :--------: | :---------: | :---------: |
| 原始模型  | SimpleCNN（未感知训练）   |   84.90%   |   55.08%    |   -29.82%   |
| 任务2     | NAT-Scratch（感知训练）   |   86.49%   |   64.23%    |   -22.26%   |
| **任务3** | **Exp2（校准+分层加权）** | **87.37%** | **68.76%**  | **-18.61%** |

**累计提升**：从原始模型在 α=+0.3 时的 55.08% 到 Exp2 的 68.76%，**提升 13.68 个百分点**，精度跌幅从 29.82% 缩小至 18.61%，相对改善 **37.6%**。

## 5. 对拓展研究的启示

- 分层加权是性价比最高的改进方向，可进一步探索更精细的层到 α 映射策略（如逐层可学习的 α 范围）
- 残差校准模块目前仅加在 fc 层前，可尝试在 conv3/conv4 后也插入轻量校准，补偿中层累积误差
- 非对称采样的失败提示：训练 epoch 足够时，采样策略的重要性下降，应将优化重点放在架构和损失函数层面
- 负向 α 退化问题可通过保留一定的负向大失真训练比例来缓解（如将浅层 α 范围设为 [-0.2, 0.2] 而非 [-0.15, 0.15]）
