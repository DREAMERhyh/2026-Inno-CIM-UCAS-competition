# 任务2：非线性感知训练（NAT）—— ResNet-18 实验总结

## 1. 实验概述
本实验在 ResNet-18（11.17M 参数，干净基线 92.09%）上实施**非线性感知训练（NAT）**，在训练阶段向所有 Conv2d 和 Linear 输入端注入随机非线性失真（α ∈ [-0.3, 0.3]，每 batch 均匀采样），使模型在部署前适应存算一体芯片的模拟域误差。系统对比两种策略：**微调（Fine-tuning）** 从干净预训练权重出发训练 80 epoch，**从头训练（From Scratch）** 随机初始化训练 120 epoch。

**实验配置**：
- 模型：ResNet-18（18 层残差网络，11,173,962 参数）
- 干净基线：92.09%（任务1 未感知训练的模型）
- α 策略：每 batch 从 [-0.3, 0.3] 均匀随机采样
- 优化器：SGD + momentum=0.9 + CosineAnnealingLR
- Fine-tuning：80 epochs，lr=1e-3，起点为 checkpoints/resnet18/best_model.pth
- Scratch：120 epochs，lr=0.01，随机初始化

## 2. 干净精度与泛化性

| 策略                  | 干净准确率 | 最佳 Epoch | 与基线差值 |
| --------------------- | :--------: | :--------: | :--------: |
| 任务1 基线（未感知）  |   92.09%   |     81     |     —      |
| NAT Fine-tuning 80ep  |   91.99%   |     77     |   -0.10%   |
| **NAT Scratch 120ep** | **92.27%** |     93     | **+0.18%** |

**关键发现一：NAT 对 ResNet-18 的干净精度影响微弱。** 与 SimpleCNN 上 NAT-Scratch 带来 +1.59% 的显著正则化增益不同，ResNet-18 的 NAT-Scratch 干净精度仅比基线高 0.18%。残差网络本身的强大表达能力在干净数据上已接近饱和，NAT 注入的失真信号提供的额外正则化空间极为有限。

### 3.3 关键发现

**发现二：NAT 对 ResNet-18 的中等失真（|α|=0.2）有显著改善，但对极限失真（|α|=0.3）几乎无效。**

在 α=-0.2 时，NAT-Scratch 将精度从 32.98% 提升至 51.82%（**+18.84%**），是跨所有实验的最大单项提升。但在 α=±0.3 时，提升微乎其微——α=-0.3 从 12.38% → 18.65%（+6.27%），α=+0.3 从 17.08% → 15.64%（**反而下降 1.44%**）。NAT-Scratch 在极限失真下出现了负提升，这是 SimpleCNN 上从未观察到的现象。

**原因分析**：ResNet-18 有 18 个非线性注入点，在 |α|=0.3 时，残差连接的误差放大效应压倒了感知训练的补偿效果。即使模型在训练中"见过"强失真，18 层残差路径中失真信号的反复叠加使得最终的特征表达已不可恢复。NAT 只能帮助模型在"信号尚未被彻底摧毁"的失真强度下更好地提取信息，但无法阻止残差结构本身的误差放大机制。

**发现三：Fine-tuning 在 α=+0.3 时反而优于 Scratch（19.89% vs 15.64%），这是三模型（SimpleCNN/VGG/ResNet）中首次出现的反常现象。**

在所有其他实验中（SimpleCNN、后续将分析的 VGG-11），Scratch 全面优于 Fine-tuning。但 ResNet-18 在 α=+0.3 时打破了这个规律——微调模型保留了预训练权重的部分干净特征编码能力，在极限失真下反而比"从头在失真环境中长大"的 Scratch 模型多保留了一些信息。这可能是因为 Scratch 模型的卷积核在 120 个 epoch 的失真训练中过度适应了失真分布，反而丢失了从失真信号中提取残差信息的能力。

| 干净精度      |      91.99%      |  **92.27%**   |         Scratch         |
| α=±0.1 鲁棒性 |      81-85%      |  **84-87%**   |         Scratch         |
| α=±0.2 鲁棒性 |      42-45%      |  **48-52%**   |   Scratch（大幅领先）   |
| α=+0.3 鲁棒性 |    **19.89%**    |    15.64%     | **Fine-tuning（反常）** |
| α=-0.3 鲁棒性 |      13.34%      |  **18.65%**   |         Scratch         |

**发现四：Scratch 在大多数失真强度下优于 Fine-tuning，但在极限正向失真下出现反常退化。** 这一现象揭示了一个重要的复杂性——对于残差网络，感知训练的效果并非单调的"更多训练 = 更好"。在某个失真强度阈值之后，残差连接的误差放大效应成为主导因素，训练策略的影响退居次要。

## 5. 与 SimpleCNN NAT 的跨架构对比

### 5.1 NAT 的绝对效果对比

| 指标                    |      SimpleCNN      |                ResNet-18                 |
| ----------------------- | :-----------------: | :--------------------------------------: |
| 干净基线                |       84.90%        |                  92.09%                  |
| NAT-Scratch 干净精度    |   86.49% (+1.59%)   |             92.27% (+0.18%)              |
| 基线 α=+0.3 精度        |       55.08%        |                  17.08%                  |
| NAT-Scratch α=+0.3 精度 | **64.23% (+9.15%)** |           **15.64% (-1.44%)**            |
| 基线 α=-0.2 精度        |       79.99%        |                  32.98%                  |
| NAT-Scratch α=-0.2 精度 |   84.02% (+4.03%)   |           **51.82% (+18.84%)**           |
| 核心结论                |    NAT 全面有效     | NAT 仅在中等失真有效，极限失真无效或负效 |

### 5.2 为什么 NAT 对 ResNet-18 的极限失真无效？

**残差连接的误差放大是不可逆的结构性问题。** 在 SimpleCNN 中，每层输出 = F(x)，F 内部注入一次失真。经过 5 层，失真信号被线性传递和变换，但仍保留了部分可恢复的信息。NAT 训练让 F 学会了"从失真信号中提取有效特征"。

在 ResNet-18 中，每层输出 = F(x_distorted) + x_distorted。F 内部的两个 Conv 各注入一次失真，残差加法将两重失真合并。经过 8 个 BasicBlock（16 个 Conv），失真信号在残差路径中被反复叠加——第 n 层的输入已经包含了前 n-1 层所有失真信号的叠加和。当 |α|=0.3 时，经过 16 次叠加的失真信号已完全淹没了原始输入的信息内容。NAT 训练无法改变残差连接的结构性放大效应——它只能让 F 学会"在失真环境中工作"，但无法阻止失真环境本身随着深度加深而指数级恶化。

## 6. 训练过程的收敛性分析

| 指标            | Fine-tuning 80ep | Scratch 120ep |
| --------------- | :--------------: | :-----------: |
| 最终训练精度    |      99.96%      |    99.97%     |
| 最终测试精度    |      91.30%      |    92.13%     |
| 训练-测试精度差 |    **8.66%**     |     7.84%     |
| 最佳 epoch      |        77        |      93       |

**发现五：ResNet-18 的 NAT 训练存在严重的过拟合。** Fine-tuning 的训练精度高达 99.96%（几乎完全拟合训练集），但测试精度仅 91.30%，差距 8.66%。Scratch 同样存在训练精度 99.97% vs 测试 92.13% 的巨大鸿沟。这与 SimpleCNN 的 NAT 训练形成对比——SimpleCNN 的训练-测试差距通常在 2-4% 以内。ResNet-18 的 11.17M 参数在 CIFAR-10 上天然存在过拟合倾向，NAT 注入的失真信号虽然提供了正则化，但不足以完全抑制这种倾向。

## 7. 对后续任务的启示

1. **ResNet-18 不适合直接部署在存算一体芯片上，即使经过 NAT 训练。** α=±0.3 时精度仅 16-19%，远低于可接受水平。残差连接的结构性误差放大效应无法通过训练策略消除。

2. **如果必须使用 ResNet，需在架构层面进行改造。** 任务3 的 FeatureCalibration 在 SimpleCNN 上效果显著（fc 层余弦从 0.90 提升），但对 ResNet-18，问题从 layer1 就开始——需要在每个 BasicBlock 的残差加法后插入校准模块，而非仅在 fc 前。

3. **中等失真区间（|α|=0.2）的显著改善提供了希望。** NAT-Scratch 在 α=-0.2 时从 32.98% 提升至 51.82%（+18.84%），说明残差网络并非完全无法适应失真——只要失真强度没有越过某个"临界点"，NAT 仍能发挥作用。如果芯片的 α 可以控制在这个临界点以下（如通过硬件校准将 |α| 控制在 ≤0.2），ResNet-18 的部署可行性将大幅提高。
