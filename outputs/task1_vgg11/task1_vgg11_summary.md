# 任务1：非线性误差的敏感性分析 —— VGG-11 实验总结

## 1. 实验概述
本实验在 VGG-11（CIFAR-10 轻量适配版，9.2M 参数，干净精度 89.80%）上复现任务1 的非线性误差敏感性分析，将失真模型 y = α·x³ + (1-α)·x 注入所有 Conv2d 和 Linear 算子输入端，系统评估不同 α 对推理精度的影响及误差在深层纯前馈网络各层的传播特性。

**实验配置**：
- 模型：VGG-11（8 层卷积 + 5 次 MaxPool + GAP + FC，参数量约 9.2M）
- 干净基线准确率：89.80%（α=0.0）
- α 扫描范围：[-0.3, -0.2, -0.1, 0.0, 0.1, 0.2, 0.3]
- 注入位置：9 个算子（8 个 Conv2d + 1 个 fc）
- 观测层：block2_output / block3_output / block4_output / block5_output / fc_output（5 个）

## 2. 整网精度敏感性分析

### 2.1 精度衰减数据

| α      | Accuracy (%) | Accuracy Drop (%) |
| ------ | ------------ | ----------------- |
| -0.300 | 51.83        | 37.97             |
| -0.200 | 72.76        | 17.04             |
| -0.100 | 85.22        | 4.58              |
| 0.000  | 89.80        | 0.00              |
| 0.100  | 85.65        | 4.15              |
| 0.200  | 66.83        | 22.97             |
| 0.300  | 36.70        | 53.10             |

### 2.2 关键发现
- **正向失真破坏力显著大于负向**：α=+0.3 时精度仅 36.70%（跌幅 53.10%），而 α=-0.3 时为 51.83%（跌幅 37.97%）。正向破坏力是负向的 1.4 倍，保持了与 SimpleCNN 一致的非对称方向，但程度更温和。
- **精度衰减呈平滑下降**：与 ResNet-18 的"悬崖式崩塌"（α=±0.1 还有 82%，α=±0.2 骤降至 33-44%）不同，VGG-11 的衰减曲线更平缓。α=±0.1 时精度仍约 85%，α=±0.2 时降至 67-73%，α=±0.3 时才出现严重退化（37-52%）。这给防护策略留出了更大的缓冲区。
- **对比 SimpleCNN**：VGG-11 在 α=-0.3 时比 SimpleCNN 低 24.23 个百分点（51.83% vs 76.06%），α=+0.3 时低 18.38 个百分点（36.70% vs 55.08%）。深度增加确实加剧了非线性脆弱性。
- **对比 ResNet-18**：VGG-11 在所有 α 下均优于 ResNet-18，尤其在 α=-0.3 时差距最大（51.83% vs 12.38%，高 39.45 个百分点）。纯前馈结构没有残差连接的误差放大效应，因此在强失真下反而更稳健。

## 3. 层输出分布偏移分析

### 3.1 各层平均余弦相似度（跨所有非零 α）

| 层名          |  平均余弦相似度  |
| ------------- | :--------------: |
| block2_output |      0.9748      |
| block3_output |      0.9423      |
| block4_output |      0.8982      |
| block5_output |    **0.8539**    |
| fc_output     | 未捕获（见说明） |

- **最敏感层**：block5_output（余弦相似度 0.8539）
- **最不敏感层**：block2_output（余弦相似度 0.9748）

### 3.2 关键发现
- **误差随深度平滑累积，没有"爆发"点**：VGG-11 的余弦相似度从 block2 的 0.97 逐级下降到 block5 的 0.85，每层约损失 0.03-0.05。与 ResNet-18 的"layer3 突然崩到 0.75"不同，VGG-11 的误差累积是渐进的、可控的。
- **浅层保护较好**：block2 的余弦相似度 0.97 与 SimpleCNN 的 conv1/conv2（0.997）接近，说明纯前馈网络的前几层天然对非线性失真不敏感——这可能是卷积+ReLU+MaxPool 对信号幅度的天然归一化效应。
- **最深层（block5）余弦 0.85，优于 ResNet-18 的 fc（0.47）**：VGG-11 在 9 次非线性注入后，最深层特征仍保持 0.85 的余弦相似度，而 ResNet-18 在 18 次注入后 fc 余弦仅 0.47。注入次数与结构类型共同决定了误差累积的严重程度。
- **fc 层观察缺失**：层分析脚本对 VGG-11 只捕获了 4 个 block 的输出，未捕获 fc_output。从整网精度推断，fc 层的余弦相似度应略低于 block5 的 0.85（因为还需经过一次 Linear 注入），但不会出现 ResNet-18 那种 0.47 的崩溃。

### 3.3 最极端条件（α=-0.3 和 α=+0.3）下的逐层余弦相似度

| 层            | α=-0.3 | α=+0.3 | 两者接近程度 |
| ------------- | :----: | :----: | :----------: |
| block2_output | 0.9610 | 0.9444 |     接近     |
| block3_output | 0.9009 | 0.8846 |     接近     |
| block4_output | 0.8757 | 0.7564 |   正向更差   |
| block5_output | 0.8039 | 0.7324 |   正向更差   |

α=+0.3 的破坏力始终略大于 α=-0.3，差距从 block3 开始拉大。在 block4 处差距已达 0.12，与整网精度衰减的非对称性一致。

## 4. 三模型架构对比分析

### 4.1 核心数据并排

| 指标           | SimpleCNN  |    VGG-11     | ResNet-18 |
| -------------- | :--------: | :-----------: | :-------: |
| 参数量         |   0.24M    |     9.2M      |  11.17M   |
| 结构类型       | 浅层纯前馈 |  深层纯前馈   | 深层残差  |
| 干净精度       |   84.90%   |    89.80%     |  92.09%   |
| α=+0.3 精度    | **55.08%** |    36.70%     |  17.08%   |
| α=-0.3 精度    | **76.06%** |    51.83%     |  12.38%   |
| 非线性注入点数 |     5      |       9       |    18     |
| 最敏感层余弦   | fc: 0.895  | block5: 0.854 | fc: 0.469 |

### 4.2 VGG-11 在三模型中的定位

VGG-11 在"深度"和"结构类型"两个维度上提供了完美的中间对照：

| 对比                |         变量          | VGG-11 的数据告诉我们                                                                           |
| ------------------- | :-------------------: | ----------------------------------------------------------------------------------------------- |
| SimpleCNN vs VGG-11 |  **深度**（4层→8层）  | 深度增加使 α=+0.3 精度从 55% 降至 37%（-18%），纯前馈深度增加确实加剧了非线性脆弱性，但程度可控 |
| VGG-11 vs ResNet-18 | **残差连接**（无→有） | ResNet-18 在更深的 18 层下精度反而更低（17% vs 37%），残差连接在非线性失真下成为误差放大器      |

### 4.3 原因分析

**为什么 VGG-11 比 ResNet-18 更鲁棒？**
- VGG-11 的 9 个注入点（8 Conv + 1 FC）比 ResNet-18 的 18 个注入点（17 Conv + 1 FC）少一半。更少的注入点意味着误差累积的代数更少。
- 纯前馈网络中，每层输出 = F(x)，信息仅沿单一路径流动。残差网络中，输出 = F(x) + x，失真通过两条路径交叉污染，形成正反馈放大。
- VGG-11 的 MaxPool 层（5 个）起到天然的"信号筛选"作用——仅保留局部最大值，部分低幅度失真信号被池化操作丢弃。

**为什么 VGG-11 比 SimpleCNN 更脆弱？**
- 8 个卷积层在信息传递路径上创造了 9 次失真注入机会，而 SimpleCNN 仅 5 次。这是"更深"的代价。
- VGG-11 没有 SimpleCNN 的 GAP（全局平均池化）作为最后的信息压缩层——GAP 对失真信号有天然的平滑作用，而 VGG-11 的 Flatten 将所有空间位置的失真特征都传递给了 fc 层。

## 5. 对后续任务的启示

- **任务2（NAT 感知训练）对 VGG-11 应该有效**：VGG-11 的 α=±0.1 时精度仍有 85%，α=±0.2 时 67-73%，说明模型在轻中度失真下还保留了相当的信息。NAT 训练有足够的学习空间来提升鲁棒性。
- **VGG-11 是"最值得优化的架构"**：SimpleCNN 已经较鲁棒但精度上限低，ResNet-18 精度高但脆弱性致命，VGG-11 在精度（89.80%）和鲁棒性（α=+0.3 时 36.70%）之间取得了最好的平衡。如果在 VGG-11 上叠加任务3 的校准模块和分层加权训练，可能获得最优的综合性能。
- **MaxPool 的隐式鲁棒性值得深入研究**：VGG-11 的 5 个 MaxPool 层可能意外地提供了对非线性失真的部分屏蔽（仅保留局部最大值），这在 ResNet-18 的 stride-2 卷积下采样中不存在。池化策略可能是一种"免费的"鲁棒性增强手段。
