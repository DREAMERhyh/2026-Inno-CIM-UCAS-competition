# 拓展1：三模型干净权重 vs NAT Scratch 横向对比 —— 实验总结

## 1. 实验概述
本实验在同一坐标系下对比三个不同架构的**干净模型**与其对应的**NAT-Scratch（非线性感知从头训练）模型**，在 α ∈ [-0.3, 0.3] 范围内的精度衰减曲线，系统回答：感知训练对不同架构的鲁棒性提升效果是否存在本质差异？架构类型（浅层纯前馈、深层纯前馈、深层残差）如何影响 NAT 的有效性？

**实验配置**：
- 干净模型：SimpleCNN (0.24M) / VGG-11 (9.23M) / ResNet-18 (11.17M)
- NAT 模型：对应架构的 NAT-Scratch 120 epoch 权重
- α 扫描范围：[-0.3, -0.2, -0.1, 0.0, 0.1, 0.2, 0.3]
- 评估指标：各 α 下的绝对精度、相对跌幅、NAT 提升幅度

## 2. 全局对比总表

| 模型              | 参数量 |  干净精度  | α=+0.3 精度 | α=+0.3 跌幅 | 架构类型              |
| ----------------- | :----: | :--------: | :---------: | :---------: | --------------------- |
| Clean-SimpleCNN   | 0.24M  |   84.90%   |   55.08%    |   -29.82%   | 浅层纯前馈            |
| **NAT-SimpleCNN** | 0.24M  | **86.49%** | **64.23%**  | **-22.26%** | (+1.59%) (+9.15%)     |
| Clean-VGG11       | 9.23M  |   89.80%   |   36.70%    |   -53.10%   | 深层纯前馈            |
| **NAT-VGG11**     | 9.23M  | **90.18%** | **44.74%**  | **-45.44%** | (+0.38%) (+8.04%)     |
| Clean-ResNet18    | 11.17M |   92.09%   |   17.08%    |   -75.01%   | 深层残差              |
| **NAT-ResNet18**  | 11.17M | **92.27%** | **15.64%**  | **-76.63%** | (+0.18%) (**-1.44%**) |

## 3. NAT 提升效果的分层分析

### 3.1 全 α 区间的 NAT 提升对比

|    α     | SimpleCNN 提升 | VGG-11 提升 | ResNet-18 提升 |  最强受益者   |
| :------: | :------------: | :---------: | :------------: | :-----------: |
|   -0.3   |     +5.48%     | **+12.89%** |     +6.27%     |  **VGG-11**   |
|   -0.2   |     +4.03%     |   +6.72%    |  **+18.84%**   | **ResNet-18** |
|   -0.1   |     +2.28%     |   +2.51%    |     +2.58%     |   三者接近    |
|   0.0    |     +1.59%     |   +0.38%    |     +0.18%     |   SimpleCNN   |
|   +0.1   |     +2.27%     |   +1.38%    |     +4.04%     |   ResNet-18   |
|   +0.2   |     +6.32%     |   +6.46%    |     +4.55%     |    VGG-11     |
| **+0.3** |   **+9.15%**   | **+8.04%**  |   **-1.44%**   | **SimpleCNN** |

### 3.2 关键发现

**发现一：NAT 对三种架构的干净精度提升均有限，但对 SimpleCNN 的正则化效应最显著。**

NAT-Scratch 干净精度提升依次为 SimpleCNN +1.59%、VGG-11 +0.38%、ResNet-18 +0.18%。这反映了各架构在干净数据上的表达能力饱和度：SimpleCNN（84.90%）仍有提升空间，NAT 注入的失真信号提供了有效的隐式正则化；VGG-11（89.80%）和 ResNet-18（92.09%）的干净精度已接近 CIFAR-10 在该架构下的上限，NAT 的正则化增益自然递减。

**发现二：在极限正向失真（α=+0.3）下，NAT 效果呈"纯前馈有效、残差退化"的鲜明两极分化。**

SimpleCNN 提升 +9.15%，VGG-11 提升 +8.04%，两者都是稳健的正收益。但 ResNet-18 反而**退化 1.44%**——NAT-Scratch 在 α=+0.3 时精度（15.64%）甚至低于干净模型（17.08%）。这是全部实验中最反直觉的结果之一：**在失真环境中从头训练的模型，反而比从未见过失真的干净模型在强失真下表现更差。**

物理原因：ResNet-18 的 18 个失真注入点 + 残差连接的误差放大效应，使得在 |α|=0.3 时，失真信号经过 16 层残差叠加后已完全淹没原始信息。NAT-Scratch 在 120 个 epoch 的失真训练中，卷积核过度适应了训练时的失真分布（α ∈ [-0.3, 0.3] 均匀采样），反而丧失了干净模型在极端失真下通过"随机猜测"侥幸命中的能力。这类似于"过度专业化"——在一个过于严苛的环境中训练，有时会不如一个从未见过该环境的"通才"。

**发现三：在负向失真（α=-0.3）下，VGG-11 的 NAT 提升是三模型中最高的（+12.89%）。**

这与 VGG-11 的基线特性完美契合：干净 VGG-11 在 α=-0.3 时精度 51.83%——信号已被破坏但仍保留了大量可恢复的信息。SimpleCNN 的基线已在 76.06%（天花板限制提升空间），ResNet-18 的基线仅 12.38%（地板效应使 NAT 无从发力）。VGG-11 恰好处于 NAT 能发挥最大作用的"甜蜜点"。

**发现四：在中等负向失真（α=-0.2）下，ResNet-18 的 NAT 提升反而是三模型中最大的（+18.84%）。**

这揭示了一个精确的规律：ResNet-18 的 NAT 存在一个"有效窗口"——当失真强度刚好让信号受损但未崩溃时（α=-0.2 时精度从 32.98% → 51.82%），NAT 的效果极强。但当失真突破临界点（|α|≥0.3，精度跌破 20%），NAT 完全失效甚至反噬。这一"窗口效应"是残差网络独有的——纯前馈网络没有如此陡峭的有效-失效边界。

## 4. NAT 效果的架构依赖性机制分析

### 4.1 注入点数量 vs NAT 极限效果

| 架构      | 注入点数量 | α=+0.3 NAT 提升 | α=-0.3 NAT 提升 |
| --------- | :--------: | :-------------: | :-------------: |
| SimpleCNN |     5      |   **+9.15%**    |     +5.48%      |
| VGG-11    |     9      |     +8.04%      |   **+12.89%**   |
| ResNet-18 |     18     |   **-1.44%**    |     +6.27%      |

注入点数量与极限正向 NAT 提升呈严格负相关：5 → 9 → 18 点，提升从 +9.15% → +8.04% → -1.44%。当失真信号经过的注入点超过某个临界值（约 10 个），NAT 的训练无法再有效补偿累积失真。

### 4.2 结构类型 vs NAT 的有效区间

| 架构      | 结构特征             | NAT 有效区间 | NAT 无效/退化区间 |
| --------- | -------------------- | :----------: | :---------------: |
| SimpleCNN | 浅层纯前馈           |    全部 α    |        无         |
| VGG-11    | 深层纯前馈 + MaxPool |    全部 α    |        无         |
| ResNet-18 | 深层残差             | \|α\| ≤ 0.2  |    \|α\| ≥ 0.3    |

纯前馈网络（无论浅层还是深层）的 NAT 在所有失真强度下均有效。残差网络的 NAT 仅在中等及以下失真强度有效，极限失真下退化。MaxPool 的存在（VGG-11）提供了额外的量化噪声缓冲能力，但对 NAT 的有效区间没有结构性影响。

## 5. 各架构 NAT 效果的综合评价

### SimpleCNN：极限正向最强
- α=+0.3 时 NAT 提升 +9.15%，三模型中最高
- α=-0.3 时 NAT 提升 +5.48%，受限于基线已较高（76.06%）的天花板效应
- **综合评价**：受限于低精度天花板（NAT 后也仅 86.49%），但鲁棒性提升最强且最稳定

### VGG-11：最均衡的 NAT 受益者
- 所有 α 区间均提供稳健的 2-13% 增益，无退化现象
- α=-0.3 时 +12.89%，三模型中负向最大单项提升
- α=+0.3 时 +8.04%，仅略低于 SimpleCNN 的 +9.15%
- **综合评价**：没有 SimpleCNN 的低精度天花板限制，没有 ResNet-18 的结构性缺陷，是 NAT 效果最均衡、最可预测的架构

### ResNet-18：极端化的 NAT 受益者
- α=-0.2 时 +18.84%，三模型中任何区间的最大单项提升
- α=+0.3 时 **-1.44%**，三模型中唯一的 NAT 退化现象
- **综合评价**：NAT 效果高度依赖失真强度，"窗口效应"显著。在可接受的失真范围内（|α|≤0.2）受益最大，但越过临界点后完全失效
