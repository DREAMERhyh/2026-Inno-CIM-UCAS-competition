# 拓展研究3：量化误差与非线性误差联合影响 —— VGG-11 实验总结

## 1. 实验概述
本实验在 VGG-11（CIFAR-10 轻量适配版，9.2M 参数，干净精度 89.73%）上复现拓展研究3 的联合误差分析。在推理时同时注入**非线性失真**（模拟域 MAC 固有）和**量化误差**（ADC 模数转换精度损失），系统分析单独量化影响及联合影响的叠加特性，并与 SimpleCNN 和 ResNet-18 进行跨架构对比。

- **模型**：VGG-11（8 层卷积 + 5 次 MaxPool + GAP + FC，89.73% 干净精度）
- **量化比特数**：8、6、4、3、2 bit（逐样本动态缩放 QDQ）
- **非线性强度**：α ∈ [-0.3, 0.3]
- **联合注入顺序**：先非线性失真（模拟 MAC），再量化（ADC），共 35 种组合

## 2. 单独量化误差影响

|     Bit      |   VGG-11   | SimpleCNN  | ResNet-18  | 分析                          |
| :----------: | :--------: | :--------: | :--------: | ----------------------------- |
| 32（无量化） |   89.73%   |   84.81%   |   92.08%   | 干净基线                      |
|      8       |   89.73%   |   84.81%   |   92.08%   | **8bit 三模型均无损**         |
|      6       |   89.59%   |   84.58%   |   91.81%   | 6bit 仅损失 0.14%，几乎无影响 |
|    **4**     | **86.59%** | **74.71%** | **88.48%** | 4bit 仅损失 3.14%             |
|      3       |   51.46%   |   28.99%   |   59.94%   | 3bit 精度腰斩但仍维持 51%     |
|      2       |   11.03%   |   11.08%   |   10.54%   | 2bit 完全失效                 |

**关键发现一：VGG-11 的量化鲁棒性接近 ResNet-18，大幅优于 SimpleCNN。**

在 4bit 量化下，VGG-11 仅损失 3.14%（89.73% → 86.59%），与 ResNet-18 的 3.60% 损失几乎持平，远优于 SimpleCNN 的 10.10%。在 3bit 下，VGG-11 保持 51.46%（SimpleCNN 仅 28.99%）。深层纯前馈结构 + MaxPool 对量化噪声有天然的缓冲作用——MaxPool 的局部最大值筛选机制使量化误差的随机抖动被部分抑制，因为最大值在量化-反量化前后更可能保持在同一位置。

## 3. 联合误差影响（α=+0.3, bit=4）

| 指标                      |         VGG-11          |        SimpleCNN         |        ResNet-18        |
| ------------------------- | :---------------------: | :----------------------: | :---------------------: |
| 仅非线性（α=+0.3, 32bit） |         36.74%          |          54.92%          |         16.99%          |
| 仅量化（α=0, 4bit）       |         86.59%          |          74.71%          |         88.48%          |
| 单独跌幅之和              | 53.10% + 3.14% = 56.24% | 29.89% + 10.10% = 39.99% | 75.01% + 3.60% = 78.61% |
| 联合实际精度              |       **43.27%**        |        **41.24%**        |       **17.38%**        |
| 联合跌幅                  |         46.46%          |          43.57%          |         74.70%          |
| **超加性判断**            |     **亚线性抵消**      |        超加性恶化        |       亚线性抵消        |

**关键发现二：VGG-11 出现了"反直觉"的亚线性抵消——量化反而改善了非线性失真下的精度。**

在 α=+0.3 时，32bit 纯非线性精度为 36.74%，但叠加 4bit 量化后精度反而**提升到 43.27%**（+6.53%）。这与 SimpleCNN 的超加性恶化（41.24% vs 预期 44.82%）和 ResNet-18 的"地板效应抵消"（非线性已将模型摧毁，量化无从破坏）有着本质不同的物理机制。

**"量化改善精度"的物理机制**：这种反直觉现象在信号处理中被称为**随机共振（Stochastic Resonance）或抖动去相关（Dithering）**。非线性失真是确定性的、输入幅度相关的畸变——某些激活值被系统地推向分类边界的错误一侧。量化噪声引入的微小随机扰动打破了非线性失真的确定性映射，使得部分被"困"在错误分类区域的样本因随机抖动而跳出。这类似于在音频处理中故意加入少量噪声来消除量化失真（dithering 技术）。

从联合误差 CSV 中可以看到完整的 dithering 效应曲线：
- α=+0.3, 8bit（无量化噪声）：36.74%
- α=+0.3, 6bit（极微量量化噪声）：37.13%
- α=+0.3, 4bit（适量量化噪声）：**43.27%**（最优 dithering 点）
- α=+0.3, 3bit（过量量化噪声）：42.97%（开始回落）
- α=+0.3, 2bit（量化噪声淹没信号）：9.98%（崩溃）

精度随量化噪声增加先上升后下降，存在一个最优的"噪声剂量"——4bit 恰好提供了足够的随机扰动来打破非线性失真的确定性破坏，又不至于噪声过大淹没信号本身。

## 4. 全 α × bit 联合效应分析

### 4.1 Dithering 效应出现的条件

|    α     | 32bit 精度 | 4bit 精度  |        Dithering 增益        |
| :------: | :--------: | :--------: | :--------------------------: |
|   -0.3   |   51.83%   |   43.93%   |     **-7.90%**（纯破坏）     |
|   -0.2   |   72.76%   |   63.98%   |            -8.78%            |
|   -0.1   |   85.22%   |   78.88%   |            -6.34%            |
|   0.0    |   89.80%   |   86.59%   |     -3.21%（纯量化损失）     |
|   +0.1   |   85.65%   |   85.45%   |      -0.20%（几乎无损）      |
|   +0.2   |   66.83%   |   71.21%   | **+4.38%**（dithering 开始） |
| **+0.3** | **36.74%** | **43.27%** | **+6.53%**（最强 dithering） |

Dithering 效应仅在**正向大失真**（α=+0.2, +0.3）时出现，负向失真下没有。这与任务1 发现的非线性非对称性一致——正向失真（α>0）的物理机制（大信号被放大）导致了系统性的分类边界偏移，量化噪声的随机扰动恰好能打破这种系统偏移；而负向失真（大信号被压缩）的破坏模式不同，量化噪声无法提供相同的"去偏"效果。

### 4.2 α=+0.2 时的有趣现象

α=+0.2 时，VGG-11 的纯非线性精度 66.83%，叠加 4bit 量化后升至 71.21%（+4.38%），甚至**反超了 3bit 量化（59.77%）和 2bit 量化（9.99%）**。4bit 恰好是 dithering 的"甜区"——噪声强度刚好。

### 4.3 α=+0.1 时的独特表现

α=+0.1 时，4bit 联合精度（85.45%）几乎与 32bit 纯非线性精度（85.65%）持平，仅差 0.20%。VGG-11 在轻失真区间实现了"几乎无额外量化损失"——这是 SimpleCNN（α=+0.1, 4bit 损失 2.37%）和 ResNet-18（α=+0.1, 4bit 损失 7.09%）都无法做到的。

## 5. 三模型联合误差全面对比

| 维度                  |      SimpleCNN       |           VGG-11           |       ResNet-18        |
| --------------------- | :------------------: | :------------------------: | :--------------------: |
| 干净精度              |        84.81%        |           89.73%           |         92.08%         |
| 4bit 量化悬崖         |  **有**（-10.10%）   |      **无**（-3.14%）      |    **无**（-3.60%）    |
| 非线性 α=+0.3 精度    |        55.08%        |           36.70%           |         17.08%         |
| α=+0.3, 4bit 联合精度 |        41.24%        |         **43.27%**         |         17.38%         |
| 联合效应类型          |      超加性恶化      | 亚线性抵消 + **Dithering** | 亚线性抵消（地板效应） |
| Dithering 效应        |          无          |  **有**（+6.53% 在 4bit）  |    无（精度已触底）    |
| 综合评估              | 非线性鲁棒但量化脆弱 |   **最均衡**：两项都鲁棒   |  量化鲁棒但非线性致命  |

**关键发现三：VGG-11 是三模型中联合误差下表现最均衡的架构。**

它既没有 SimpleCNN 的量化悬崖问题（4bit 损失仅 3.14% vs 10.10%），也没有 ResNet-18 的非线性崩溃问题（α=+0.3 时 36.70% vs 17.08%）。更独特的是，它首次展示了 dithering 效应——量化噪声在特定条件下可以**部分抵消**非线性失真的破坏。这使得 VGG-11 在联合误差 α=+0.3, bit=4 下取得了三模型中最高的联合精度（43.27%）。

## 6. Dithering 效应对赛题的工程启示

1. **量化不总是"有害"的**：在存算一体芯片中，ADC 的量化噪声通常被视为单纯的精度损失源。但 VGG-11 的实验证明，适量的量化噪声可以充当"免费的 dithering 信号"，部分抵消模拟域 MAC 的非线性失真。这在工程上具有重要价值——与其追求更高精度的 ADC（代价是功耗和面积），不如在 ADC 前主动注入已知强度的随机噪声（可控 dithering），以极低的硬件成本换取显著的非线性鲁棒性提升。

2. **最优 dithering 强度的存在性**：VGG-11 的数据清晰展示了 dithering 效应的"倒 U 型"曲线——4bit（适量）效果最优，8bit（无噪声）和 2bit（噪声过大）效果都差。这提示我们，在实际芯片设计中，ADC 精度并非越高越好，存在一个针对特定非线性模型的"最优量化比特数"。

3. **Dithering 效应是架构依赖的**：SimpleCNN 和 ResNet-18 均未观察到 dithering 效应（前者因为量化本身就造成大量损失，后者因为非线性已将模型摧毁）。VGG-11 的 MaxPool + 深层纯前馈结构似乎是 dithering 效应的"理想土壤"——MaxPool 对噪声的局部筛选 + 纯前馈路径中失真信号的确定性偏移，共同创造了 dithering 发挥作用的条件。
