# 任务1：非线性误差的敏感性分析 —— ResNet-18 实验总结

## 1. 实验概述
本实验在 ResNet-18（CIFAR-10 适配版，11.17M 参数，干净精度 92.09%）上复现任务1 的非线性误差敏感性分析，将失真模型 y = α·x³ + (1-α)·x 注入所有 Conv2d 和 Linear 算子输入端，系统评估不同 α 对推理精度的影响及误差在残差网络各层的传播特性。

**实验配置**：
- 模型：ResNet-18（18 层残差网络，4 组 BasicBlock，参数量 11,173,962）
- 干净基线准确率：92.09%（α=0.0）
- α 扫描范围：[-0.3, -0.2, -0.1, 0.0, 0.1, 0.2, 0.3]
- 注入位置：18 个算子（1 个 conv1 + 16 个 BasicBlock 内 Conv2d + 1 个 fc）
- 观测层：layer1_output / layer2_output / layer3_output / layer4_output / fc_output（5 个）

## 2. 整网精度敏感性分析

### 2.1 精度衰减数据

| α      | Accuracy (%) | Accuracy Drop (%) |
| ------ | ------------ | ----------------- |
| -0.300 | 12.38        | 79.71             |
| -0.200 | 32.98        | 59.11             |
| -0.100 | 81.64        | 10.45             |
| 0.000  | 92.09        | 0.00              |
| 0.100  | 82.78        | 9.31              |
| 0.200  | 43.97        | 48.12             |
| 0.300  | 17.08        | 75.01             |

### 2.2 关键发现
- **双向崩溃，负向更致命**：α=-0.3 时精度仅 12.38%（跌幅 79.71%），α=+0.3 时 17.08%（跌幅 75.01%）。两者均接近或低于随机猜测水平，模型几乎完全失效。
- **非对称性反转**：SimpleCNN 上正向破坏力是负向的 3.4 倍，ResNet-18 上**负向破坏力反而略大于正向**（79.71% vs 75.01%）。残差连接完全改变了失真的非对称响应模式。
- **崩塌陡峭**：α=±0.1 时精度仍有 81-83%，但 α 增大到 ±0.2 时骤降至 33-44%，增大到 ±0.3 时崩溃至 12-17%。精度衰减曲线极陡，几乎没有缓冲区间。
- **对比 SimpleCNN**：SimpleCNN 在 α=±0.3 时精度分别为 76.06%（α=-0.3）和 55.08%（α=+0.3），ResNet-18 在同等条件下分别低了 63.68 和 38.00 个百分点。深层残差网络在非线性失真面前比浅层网络脆弱得多。

## 3. 层输出分布偏移分析

### 3.1 各层平均余弦相似度（跨所有非零 α）

| 层名          | 平均余弦相似度 |
| ------------- | :------------: |
| layer1_output |     0.9309     |
| layer2_output |     0.8485     |
| layer3_output |     0.7513     |
| layer4_output |     0.6551     |
| **fc_output** |   **0.4686**   |

- **最敏感层**：fc_output（余弦相似度 0.4686）
- **最不敏感层**：layer1_output（余弦相似度 0.9309）

### 3.2 关键发现
- **误差从第一层就开始显著累积**：SimpleCNN 的 conv1/conv2 几乎不受影响（余弦>0.99），但 ResNet-18 的 layer1 余弦已降至 0.93，layer2 降至 0.85。残差连接没有阻止误差传播，反而使其更早地渗透到浅层。
- **中层（layer3/layer4）已严重失真**：余弦相似度分别降至 0.75 和 0.66。对比 SimpleCNN 的 conv3/conv4（0.98 和 0.96），ResNet-18 的中层特征表达已遭受严重破坏。
- **fc 层完全崩溃**：余弦相似度仅 0.47，远低于 SimpleCNN fc 的 0.90。在 α=-0.3 时 fc_output 余弦仅 0.143——特征向量已与干净状态几乎正交，分类决策完全随机化。
- **fc_output 的 RME 值极端异常**：α=-0.3 时 RME 高达 30.84，α=-0.2 时 14.25。这意味着 fc 层输出的均值偏移了数十倍于干净均值的幅度，分布中心发生了灾难性漂移。

| ------------- | :--------: | ------------------ |

| layer2_output |   0.754    | 开始严重退化       |

## 4. 残差连接的误差放大机制分析

### 4.1 误差注入点数量差异
ResNet-18 有 18 个非线性注入点（1 conv1 + 16 BasicBlock Conv + 1 fc），是 SimpleCNN（5 个）的 **3.6 倍**。每个 BasicBlock 包含两个 Conv2d，每个 Conv 的输入都被注入失真。残差连接使得每层的输出 = F(x_distorted) + x_distorted，而非线性失真在 F(x) 内部的两个 Conv 中各注入一次。经过 8 个 BasicBlock 的逐级叠加，误差呈指数级放大。

### 4.2 残差连接的"正反馈"效应
在标准前馈网络中，每层输入仅来自上一层的输出。但残差连接使得：

$$output = F(x) + x$$

当 x 已被前一层失真污染时，F(x) 进一步叠加失真，残差加法将两重失真合并传入下一层。这形成了类似正反馈的累积循环——失真不会被稀释，而是被"保留并叠加"。

### 4.3 与 SimpleCNN 的核心差异

| 维度           |     SimpleCNN     |    ResNet-18    |
| -------------- | :---------------: | :-------------: |
| 注入点数量     |         5         |       18        |
| α=+0.3 精度    |      55.08%       |     17.08%      |
| α=-0.3 精度    |      76.06%       |     12.38%      |
| 最敏感层余弦   |     fc: 0.895     |    fc: 0.469    |
| 浅层受影响程度 | 几乎不变（>0.99） | 已受损（~0.93） |
| 误差传播模式   |   深层集中爆发    |  全层级联放大   |

## 5. 对后续任务的启示

- **任务2（NAT 感知训练）对 ResNet-18 可能至关重要**：SimpleCNN 的 NAT 将 α=+0.3 精度从 55% 提升到 69%，但 ResNet-18 的基础精度仅 17%，即使 NAT 带来同样的相对提升幅度，绝对精度仍可能很低。需要实际验证。
- **残差连接需要针对性防护**：单纯在输入端注入失真进行感知训练，可能不足以抵消残差连接的误差放大效应。可考虑在每个 BasicBlock 的残差加法后插入归一化或校准模块。
- **任务3 的架构增强方案可能对 ResNet-18 更关键**：在 fc 层前插入 FeatureCalibration 只能保护最后的分类决策，但 ResNet-18 的问题从 layer1 就开始。需要在更浅层（layer2/layer3 输出后）也插入校准模块。
- **拓展3 的量化叠加风险**：ResNet-18 对 α=±0.1 还有 81-83% 精度，但如果叠加 4bit 量化（SimpleCNN 上单独量化损失约 10%），可能在轻失真下就跌破 70%。联合误差扫描将揭示这一风险。
