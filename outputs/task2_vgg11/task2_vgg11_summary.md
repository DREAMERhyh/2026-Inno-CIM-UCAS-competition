# 任务2：非线性感知训练（NAT）—— VGG-11 实验总结

## 1. 实验概述
本实验在 VGG-11（CIFAR-10 轻量适配版，9.2M 参数，干净基线 89.80%）上实施**非线性感知训练（NAT）**，在训练阶段向所有 Conv2d 和 Linear 输入端注入随机非线性失真（α ∈ [-0.3, 0.3]，每 batch 均匀采样），系统对比两种策略：**微调（Fine-tuning）** 从干净预训练权重出发训练 80 epoch，**从头训练（From Scratch）** 随机初始化训练 120 epoch。

**实验配置**：
- 模型：VGG-11（8 层卷积 + 5 次 MaxPool + GAP + FC，约 9.2M 参数）
- 干净基线：89.80%（任务1 未感知训练的模型）
- α 策略：每 batch 从 [-0.3, 0.3] 均匀随机采样
- 优化器：SGD + momentum=0.9 + CosineAnnealingLR
- Fine-tuning：80 epochs，lr=1e-3，起点为 checkpoints/vgg11/best_model.pth
- Scratch：120 epochs，lr=0.01，随机初始化

## 2. 干净精度与泛化性

| 策略                  | 干净准确率 | 最佳 Epoch | 与基线差值 |
| --------------------- | :--------: | :--------: | :--------: |
| 任务1 基线（未感知）  |   89.80%   |     —      |     —      |
| NAT Fine-tuning 80ep  |   89.90%   |     65     |   +0.10%   |
| **NAT Scratch 120ep** | **90.18%** |    107     | **+0.38%** |

**关键发现一：NAT 对 VGG-11 的干净精度提升微弱。** 与 SimpleCNN（+1.59%）和 ResNet-18（+0.18%）相比，VGG-11 的 NAT 正则化增益（+0.38%）介于两者之间。深层纯前馈结构的表达能力在干净数据上仍有小幅提升空间，但远不如浅层 SimpleCNN 那样从正则化中获益显著。

| -0.1     |   85.22%   |      85.63%      |  **87.73%**   |  **+2.51%**  |
| 0.0      |   89.80%   |      89.90%      |  **90.18%**   |  **+0.38%**  |
| +0.1     |   85.65%   |      86.42%      |  **87.03%**   |  **+1.38%**  |
| +0.2     |   66.83%   |      70.03%      |  **73.29%**   |  **+6.46%**  |

### 3.2 最大精度跌幅

| 模型              |   最差 α   |    精度    |    跌幅     |
| ----------------- | :--------: | :--------: | :---------: |
| 任务1 基线        |   α=+0.3   |   36.70%   |   -53.10%   |
| Fine-tuning 80ep  |   α=+0.3   |   39.96%   |   -49.94%   |
| **Scratch 120ep** | **α=+0.3** | **44.74%** | **-45.44%** |

### 3.3 关键发现

**发现二：NAT-Scratch 对 VGG-11 的所有失真强度均有稳健提升，尤其擅长负向失真。**

VGG-11 的 NAT-Scratch 在 α=-0.3 时提升最大（+12.89%），将精度从 51.83% 拉升至 64.72%。这与 VGG-11 的任务1 特性一致——VGG-11 对正向失真更敏感（任务1 中 α=+0.3 跌幅 53.10% > α=-0.3 跌幅 37.97%），NAT 的均匀 α 采样在训练中让模型"平等地"见过正负失真，而负向失真的破坏力本就较小，因此 NAT 带来的相对改善更显著。

**发现三：Fine-tuning 在 α=+0.3 时精度（39.96%）显著低于 Scratch（44.74%），差距 -4.78%。**

与 ResNet-18 上"Fine-tuning 反常优于 Scratch"的现象不同，VGG-11 恢复了 SimpleCNN 的规律——Scratch 在所有 α 下全面优于 Fine-tuning。这进一步验证了"预训练权重的干净特征偏见"假说：VGG-11 和 SimpleCNN 都是纯前馈网络，权重在干净数据上学到的特征表达模式对失真较敏感，只有通过随机初始化才能在失真环境中建立全新的、对非线性不敏感的特征提取方式。

**发现四：VGG-11 的 NAT 效果是三个模型中最为均衡的。**

| 指标                |    SimpleCNN    |     VGG-11      |          ResNet-18           |
| ------------------- | :-------------: | :-------------: | :--------------------------: |
| Scratch 干净精度    | 86.49% (+1.59%) | 90.18% (+0.38%) |       92.27% (+0.18%)        |
| Scratch α=+0.3 提升 |   **+9.15%**    |   **+8.04%**    |      **-1.44%（退化）**      |
| Scratch α=-0.3 提升 |     +5.48%      |   **+12.89%**   |            +6.27%            |
| Scratch α=-0.2 提升 |     +4.03%      |     +6.72%      |         **+18.84%**          |
| 特点                |    全面有效     |    均衡稳健     | 中等失真极有效，极限失真无效 |

VGG-11 的 NAT 既没有 SimpleCNN 那样在极限正向下的大幅提升（+9.15% vs +8.04%），也没有 ResNet-18 那样在极限失真下的退化。它在所有 α 区间都提供了 2-13% 的稳健增益，是最可预测、最可靠的 NAT 响应模式。

## 4. Fine-tuning vs Scratch 深度对比

| 维度          | Fine-tuning 80ep | Scratch 120ep |      优势方       |
| ------------- | :--------------: | :-----------: | :---------------: |
| 干净精度      |      89.90%      |  **90.18%**   |      Scratch      |
| α=±0.1 鲁棒性 |      85-86%      |  **87-88%**   |      Scratch      |
| α=±0.2 鲁棒性 |      70-75%      |  **73-79%**   |      Scratch      |
| α=+0.3 鲁棒性 |      39.96%      |  **44.74%**   | Scratch（+4.78%） |
| α=-0.3 鲁棒性 |      55.33%      |  **64.72%**   | Scratch（+9.39%） |
| 训练耗时      |     80 epoch     |   120 epoch   |    Fine-tuning    |

**发现五：Scratch 在所有失真强度下全面优于 Fine-tuning，优势随失真强度增大而扩大。**

α=±0.1 时 Scratch 仅领先约 1-2%，α=±0.2 时领先 3-8%，α=±0.3 时领先 5-9%。预训练权重在轻失真下还能通过微调部分适应，但在强失真下，"干净特征偏见"成为不可逾越的障碍——模型需要从根本上重构特征提取方式，而这只有随机初始化才能做到。

## 5. 与 SimpleCNN 和 ResNet-18 的跨架构对比

### 5.1 NAT-Scratch 绝对效果对比

| 指标                    | SimpleCNN  |   VGG-11   | ResNet-18 |
| ----------------------- | :--------: | :--------: | :-------: |
| 干净基线                |   84.90%   |   89.80%   |  92.09%   |
| NAT-Scratch 干净精度    |   86.49%   |   90.18%   |  92.27%   |
| 基线 α=+0.3 精度        |   55.08%   |   36.70%   |  17.08%   |
| NAT-Scratch α=+0.3 精度 | **64.23%** |   44.74%   |  15.64%   |
| α=+0.3 绝对提升         |   +9.15%   | **+8.04%** |  -1.44%   |
| α=+0.3 精度排名         | **第1名**  |   第2名    |   第3名   |

### 5.2 跨架构 NAT 效果规律

**发现六：NAT 对极限正向失真（α=+0.3）的提升幅度与模型结构直接相关。**

SimpleCNN（浅层纯前馈，5 注入点）：+9.15%
VGG-11（深层纯前馈，9 注入点）：+8.04%
ResNet-18（深层残差，18 注入点）：-1.44%

注入点数量越多，NAT 在极限失真下的效果越差——当失真信号的累积次数超过一定阈值后，感知训练无法再补偿结构性误差放大。VGG-11 的 9 个注入点恰好处于"有效补偿"的边界——NAT 仍有显著效果（+8.04%），但已略低于 SimpleCNN 的 +9.15%。

**发现七：VGG-11 在负向失真（α=-0.3）的 NAT 提升是三个模型中最大的（+12.89%）。**

这是因为 VGG-11 的任务1 基线在 α=-0.3 时精度 51.83%——仍有大量"可恢复"的信息。而 SimpleCNN 的基线已在 76.06%（天花板效应限制了提升空间），ResNet-18 的基线仅 12.38%（地板效应使 NAT 无从发力）。VGG-11 在负向失真下恰好处于"既有足够破坏力让 NAT 有作为，又未彻底摧毁信号让 NAT 无米之炊"的最佳区间。

## 6. 训练过程的收敛性分析

| 指标            | Fine-tuning 80ep | Scratch 120ep |
| --------------- | :--------------: | :-----------: |
| 最终训练精度    |      99.96%      |    99.92%     |
| 最终测试精度    |      89.44%      |    90.08%     |
| 训练-测试精度差 |    **10.52%**    |     9.84%     |
| 最佳 epoch      |        65        |      107      |

**发现八：VGG-11 的 NAT 训练存在严重的过拟合，程度为三模型中最重。**

Fine-tuning 的训练-测试精度差高达 10.52%（SimpleCNN 约 3-5%，ResNet-18 约 8%）。VGG-11 的 9.2M 参数在 CIFAR-10 上严重过参数化，NAT 注入的失真信号提供的正则化不足以完全抑制过拟合。但有趣的是，尽管过拟合严重，NAT-Scratch 仍然在测试集上取得了最佳的干净精度和鲁棒性——这说明"在失真环境中过拟合"与"在干净环境中过拟合"有着本质不同的泛化特性。失真环境的过拟合意味着模型学会了从失真信号中提取不变特征，而非简单记忆训练样本。

## 7. 三模型 NAT 规律总结

| 规律                 |    SimpleCNN     |       VGG-11       |           ResNet-18           |
| -------------------- | :--------------: | :----------------: | :---------------------------: |
| Scratch vs Fine-tune | Scratch 全面占优 |  Scratch 全面占优  | 极限正向下 Fine-tune 反常占优 |
| α=+0.3 NAT 效果      | +9.15%（强正效） | +8.04%（稳健正效） |      -1.44%（负效/无效）      |
| 最佳提升区间         |      α=+0.3      |       α=-0.3       |            α=-0.2             |
| 极限失真可救性       |  可救（55→64%）  |   可救（37→45%）   |       不可救（17→16%）        |
| NAT 正则化增益       |   大（+1.59%）   |    中（+0.38%）    |         微（+0.18%）          |
| 过拟合程度           |    低（~3%）     |     高（~10%）     |           中（~8%）           |

**核心结论：VGG-11 是 NAT 效果最均衡的架构。** 它没有 SimpleCNN 的天花板限制（干净精度已足够高，89.80%），也没有 ResNet-18 的结构性缺陷（残差放大效应）。它在所有失真强度下都提供了稳健的 2-13% 增益，在 α=-0.3 时甚至创造了跨模型的最大单项提升（+12.89%）。这使 VGG-11 在经过 NAT-Scratch 训练后，成为三个模型中综合性能最可靠的存算一体芯片部署候选架构。
